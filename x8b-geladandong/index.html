八年级下册 · 第五单元 · 第 18 课 · 马丽华

在长江源头
各拉丹冬

唐古拉山脉最高的一组雪山群主峰海拔 6 621 米长江从这里出发

“从这千山之巅、万水之源的藏北高原流出，开始演绎长江的故事。”

理清游踪品析冰塔林的描写体会景与情的关系

预习一：查找资料，了解各拉丹冬的地理位置和气候特点，想一想这里为什么会成为长江的源头（冰川融水汇成溪流）。作者马丽华长期在西藏工作，1987 年 3 月上旬随电影摄制组来到这里——“季节上的隆冬将尽，但严寒还将在此驻防三两个月”。

思考探究一 · 理清脉络

跟着作者走一遍冰塔林

按 → 一站一站走；也可以直接点地图上的站点。

思考探究一：理清文章的脉络，复述作者的所见所感。七个站点按时间与空间顺序排列：营地 → 冰河砾石堆 → 冰山与冰洞 → 摔倒 → 蜷卧冰山脚下 → 第二天的冰河与砾石滩 → 冰河中间的砾石堆。复述时用“地点 + 所见 + 所感”的句式，一站一句。

思考探究二作者是怎样描写冰塔林的？
远望走近穿洞细看光影想象

远望从砾石堆上四面张望，晶莹连绵的冰峰、平坦辽阔的冰河历历在目。

走近这一壁冰山像屏风，精雕细刻着各种图案。

穿洞从狭小的冰洞里爬过去，豁然又一番天地。整座冰塔林就由许多冰的庄园冰的院落组成，自成一天地。

细看挺拔的，敦实的，奇形怪状的，蜿蜒而立的。那些冰塔、冰柱、冰洞、冰廊、冰壁上徐徐垂挂冰的流苏，像长发披肩。

光影太阳偶一露面，这冰世界便熠熠烁烁，光彩夺目。

想象想象着在漫长的时光里，冰川的前进和后退，冰山的高低消长，这波纹是否就是年轮。

思考探究二。镜头一路推近：远望全景 → 走近冰壁 → 穿过冰洞 → 细看形态 → 阳光一照 → 由眼前的波纹想到千万年的年轮。写法上：由远及近、由整体到局部；比喻（屏风、庄园院落、长发披肩）；排比与叠词（挺拔的，敦实的……；熠熠烁烁）；虚实结合（最后一句是想象）。

思考探究二 · 感官

打开感官：看到的、听到的、身体感到的

晶莹连绵的冰峰、平坦辽阔的冰河历历在目。远方白色金字塔的各拉丹冬统领着冰雪劲旅，天地间浩浩苍苍。

置身于冰窟，远比想象的要温暖，穿着件腈纶棉衣，外罩一件皮夹克，居然感觉不到冷。风一刻不停地呼啸，辨不清它何来何往……把冰河上的雪粒纷纷扬扬地扫荡着，又纷纷扬扬地洒落在河滩上、冰缝里。渐渐地冰河已光滑难行。

是琼瑶仙境，静穆的晶莹和洁白。……太阳偶一露面，这冰世界便熠熠烁烁，光彩夺目。

过午的太阳强烈，冰面疏松多了，有流水漫溢出来。此刻除了风声，还有一种声音轻易便可辨别出来。那是坚冰之下的流水之声，它一刻不停……

多感官描写：眼睛看到冰峰的晶莹、光彩；耳朵听到风的呼啸、冰下的流水；身体感到冰窟的温暖、冰面的光滑与疏松。几种感觉交织，冰塔林就“立”在读者面前了。最后的“流水之声”还点出了题目——长江的源头。

一层一层打开：先只开“视觉”，请学生读出颜色、形态；再开“听觉”，体会以声衬静；再开“触觉·身体感受”，注意“远比想象的要温暖”是出人意料的真实体验。最后点“全部打开”，看几种感觉怎样交织。本页服务思考探究二和本单元“写景的角度和方法”。

思考探究三

“我要死了”和冰雪仙境，为什么写在一起？

身体：气喘吁吁 → 冻疮、高烧、不思饮食 → 摔断尾椎骨 → 头痛恶心、呼吸困难 → “我要死了” → 似乎已经衰竭

风景：眩晕的奇美 → 冰的庄园院落 → 琼瑶仙境 → 熠熠烁烁 → 坚冰下的流水之声

表达效果：① 以苦衬美——越艰难，越显得冰塔林奇美、值得“历尽艰辛去走上一遭”；② 真实可信——高原反应是亲身经历；③ 写出人在自然面前的渺小，和对自然的敬畏、热爱。

思考探究三。按 → 先画“身体”线，再画“风景”线：两条线方向相反，越往后剪刀差越大——正是在身体最糟的时候，作者看到了最美的景。可以追问：“我要死了”之后紧接“置身于冰窟，远比想象的要温暖”，这样的转折给你什么感受？

积累拓展四

品一品：这三句话有什么共同点？

1. 这一派奇美令人眩晕，造物主在这里尽情卖弄着它的无所不能的创造力。

“眩晕”：美得让人头晕目眩，是夸张的主观感受；“卖弄”：本是贬义，这里拟人，写大自然毫不吝惜地展示创造力，含着惊叹与赞美。

2. 风一刻不停地呼啸，辨不清它何来何往，仿佛自地球形成以来它就在这里川流不息，把冰河上的雪粒纷纷扬扬地扫荡着，又纷纷扬扬地洒落在河滩上、冰缝里。

删去后只剩眼前的风；保留它，风就有了“自地球形成以来”的时间纵深，显出高原的亘古、苍茫，也写出作者的想象与感慨。

3. 端详着冰山上纵横的裂纹，环绕冰山的波状皱褶，想象着在漫长的时光里，冰川的前进和后退，冰山的高低消长，这波纹是否就是年轮。

先实写（裂纹、皱褶），再虚写（想象冰川进退、高低消长），把波纹比作“年轮”，由眼前一瞬想到千万年。

共同点：都不只是客观描摹，而是融入了作者的主观感受与想象——景中有情，实中有虚。

积累拓展四。第 2 句点“删去加点部分”对比朗读两遍，感受删前删后的差别。最后按 → 出示共同点。
