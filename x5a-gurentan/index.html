五年级上册 · 第八单元 · 第 25 课 · 文言文

古人谈读书

旧书不厌百回读，熟读深思子自知。——［宋］苏轼

一《论语》二［宋］朱熹
根据要求梳理信息，把握内容要点

读准停顿　→　借注释读懂　→　梳理读书的道理　→　图解“三到”　→　背诵

本单元主题是“读书”。两段古人的话：第一段选自《论语》，记录孔子谈学习的话；第二段是宋代朱熹谈读书方法。本课落实单元要素“根据要求梳理信息”：把六句《论语》按“态度”和“方法”分一分。

读 · 一

先打开“节奏”读准停顿，再打开“注释”，最后打开“译文”对照。易错音：识（zhì）、好（hào）、吾（wú）、寝（qǐn）。六句话各自独立，是孔子在不同场合说的。

课后第 2 题 · 梳理信息

六句话，分别在说读书的什么？

态度：诚实 · 谦虚 · 勤奋 · 不满足方法：默记 · 好问 · 学思结合

按要求梳理：这句话讲的是学习态度，还是学习方法？点一点，再用自己的话说说大意。

梳理信息先定“要求”（标准），再逐句归类。有的句子既讲态度又讲方法（如“不耻下问”），两个都算对，关键是说出理由。

课后第 2 题

借助注释，读懂关键字

先自己说，再点卡片翻面核对。注意：有的字和今天的意思不一样。

重点区分：“厌”是“满足”不是“讨厌”；“识”读 zhì 是“记住”；两个“敏”意思不同（聪敏 / 勤勉）。“知”同“智”。

读 · 二

朱熹是南宋著名的思想家、教育家。“余尝谓”读出“我常说”的口吻；“眼口岂不到乎”是反问，语气上扬。易错音：矣（yǐ）、岂（qǐ）。

品 · 二

图解“三到”：为什么“心到最急”？

余尝谓读书有三到，谓心到、眼到、口到。心不在此，则眼不看仔细，心眼既不专一，却只漫浪诵读，决不能记，记亦不能久也。三到之中，心到最急。心既到矣，眼口岂不到乎？

  1. 心不在此
  2. 眼不看仔细
  3. 心眼不专一
  4. 只漫浪诵读
  5. 决不能记，记亦不能久

朱熹的意思：读书最要紧的是专心。心到了，眼睛自然看得仔细，嘴里自然读得认真。

先看“三到”是哪三到；再看“心不到”会怎样——一环扣一环，最后“决不能记，记亦不能久”；最后用反问句点明：心到了，眼口一定到。可以让学生演一演“心不在焉地读”和“专心地读”。

课后第 3 题 · 读与写

哪句话对你有启发？

联系自己的读书体会，选一句说一说、写一写。

说启发要“有例子”：原句 + 自己的一次经历 + 想法。也是单元习作“分段表述，突出重点”的小练习。

课后第 1 题

背诵 · 一

先选“全文”读熟，再一级一级挖空。想不起来，点一下空格偷看一个字。

六句各自独立，可以按“态度—方法”记：诚实（知之为知之）、好问（不耻下问）、不满足（学而不厌）、勤勉（敏以求之）、紧迫（学如不及）、学思（不如学也）。

课后第 1 题

背诵 · 二

按“三到是什么 → 心不到会怎样 → 心到最急”的顺序背。

中间一句是因果链：心不在此 → 眼不看仔细 → 漫浪诵读 → 不能记、不能久。背到这里可以看着上一页的图回忆。

回顾

古人怎样谈读书

一 · 《论语》二 · 朱熹
态度知之为知之（诚实）　不耻下问（谦虚）
学而不厌（不满足）　学如不及（勤奋）		心到最急（专心）
方法默而识之（默记）　敏以求之（勤勉求学）
以思无益，不如学也（学思结合）		读书有三到：心到、眼到、口到

梳理信息：先定好要求（如“态度”“方法”），再一句一句归类，内容要点就清楚了。下一课《忆读书》，我们梳理冰心奶奶的读书经历。

板书用“态度 / 方法”两行，回扣单元要素。可补充：《论语》是记录孔子及其弟子言行的书，“学而时习之”“温故而知新”三年级就学过。
