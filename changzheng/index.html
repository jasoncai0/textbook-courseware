七律·长征

重温革命岁月，把历史的声音留在心里。

读出磅礴的气势说说诗句的意思和情感背诵课文

看路线　→　吟全诗　→　品四联　→　读出气势　→　背下来

“七律”是七言律诗：每句七个字，一共八句，两句一联，分首联、颔联、颈联、尾联。先看长征路线，把诗里的地名“放到地图上”，诗就看得见了。

背景 · 看得见的诗

诗里的山和水，都在长征路上

首联红军不怕远征难，万水千山只等闲。

五岭五岭逶迤腾细浪，

乌蒙乌蒙磅礴走泥丸。

金沙金沙水拍云崖暖，

大渡大渡桥横铁索寒。

岷山更喜岷山千里雪，

尾句三军过后尽开颜。

1934 年 10 月，中央红军从江西瑞金等地出发，一路翻山渡河，1935 年 10 月到达陕北。这首诗写于长征即将胜利结束的时候。

按一下，路线走一段，右边亮一句诗。诗里的五个地名都是长征路上真实的山和水：五岭、乌蒙山、金沙江、大渡河、岷山。示意图只表示先后顺序和大致方位。

吟 · 七律·长征

诗意红军不怕万里远征的艰难，把千山万水都看得平平常常。连绵的五岭像翻腾的细浪，磅礴的乌蒙山像滚动的泥丸。金沙江浪拍云崖，大渡河铁索寒冷；更令人欢喜的是踏上千里雪原的岷山，红军翻过去后个个笑逐颜开。

先听老师读，再打开“节奏”跟读（七言：二二三）。打开“注释”，点“五岭”“乌蒙”“三军”看课本注释。“七律”的格律：中间两联（颔联、颈联）要对仗。

品 · 首联

红军不怕远征难，万水千山只等闲

红军不怕远征难，
万水千山只等闲。

“难”是全诗写的事实：路远、山高、水险。

“只等闲”：只当作平平常常的事——这是红军的态度。
“不怕”和“等闲”定下了全诗的基调：豪迈、乐观。

“万水千山”在诗里具体指哪些？点一点。小心，有几个诗里没写！

首联总写，后三联分写：万水千山，一联写山，一联写水，一联写雪山。

首联总写，后面三联分写。诗里写到的“万水千山”：五岭、乌蒙（山），金沙江、大渡河（水），岷山（山）。

品 · 颔联 · 课后第 2 题

五岭逶迤腾细浪，乌蒙磅礴走泥丸

五岭

实际：连绵起伏，逶迤不断
在红军眼里：不过是腾起的细浪

乌蒙

实际：高大雄伟，气势磅礴
在红军眼里：不过是滚动的泥丸

以大写小：把巍巍大山比作“细浪”“泥丸”——山越大，越显出红军不把困难放在眼里，正是首联的“只等闲”。

课后第 2 题。先说诗句意思：五岭山脉连绵起伏，在红军看来不过像翻腾着的细小波浪；乌蒙山高大雄伟，在红军脚下不过像滚动着的泥丸。再说情感：藐视困难、豪迈乐观。

品 · 颈联 · 课后第 2 题

金沙水拍云崖暖，大渡桥横铁索寒

地名景物感受 金沙水拍云崖暖 大渡桥横铁索寒

一暖一寒，对比鲜明：巧渡金沙江，轻松愉快；飞夺泸定桥，惊险紧张。

点一点卡片：“暖”和“寒”，只是在说天气吗？

课后第 2 题。1935 年 5 月，红军靠几只小船巧渡金沙江，甩开了敌军；同月，勇士们攀着铁索夺下泸定桥，渡过大渡河。“暖”“寒”既是景物的感觉，更是红军的心情。

品 · 尾联

更喜岷山千里雪，三军过后尽开颜

“更喜”：翻越了那么多险山恶水，又踏过千里雪山——胜利就在眼前，所以“更”喜。

“尽开颜”：全体红军都笑逐颜开。“尽”是“全、都”。

不怕→只等闲→暖 · 寒→更喜→尽开颜

全诗的情感：不怕困难、藐视困难、战胜困难的英雄气概和革命乐观主义精神。

尾联写胜利在望的喜悦，与首联“不怕”“等闲”首尾呼应。可以请学生说说：二万五千里，为什么到了这里才“尽开颜”？

读 · 课后第 1 题

读出磅礴的气势

/ 停顿　着重号 重读

红军 / 不怕 / 远征难，万水 / 千山 / 只等闲。

首联 · 豪迈有力

五岭 / 逶迤 / 腾细浪，乌蒙 / 磅礴 / 走泥丸。

颔联 · 举重若轻

金沙 / 水拍 / 云崖暖，大渡 / 桥横 / 铁索寒。

颈联 · 暖轻快 · 寒凝重

更喜 / 岷山 / 千里雪，三军 / 过后 / 尽开颜。

尾联 · 喜悦昂扬

课后第 1 题：朗读课文，试着读出磅礴的气势。七言诗按“二二三”停顿；“逶迤”“磅礴”要读得开阔，“细浪”“泥丸”轻巧；“暖”上扬，“寒”下沉；尾联声音放开。

课后第 1 题

背一背：一级一级挖空

先选“全文”读熟，再“挖一半”“只留首字”，最后“全部背出”。想不起来，点一下空格偷看一个字。提示：按长征路线背——五岭 → 乌蒙 → 金沙 → 大渡 → 岷山。

借路线图背诵：首联总写“不怕”，中间四句按路线依次是两座山、两条河，尾联写雪山和喜悦。

回顾

一首诗，二万五千里

七律·长征
首联　总写：不怕远征难　只等闲
颔联　写山：五岭 — 细浪　乌蒙 — 泥丸（以大写小）
颈联　写水：金沙 — 暖　大渡 — 寒（一暖一寒）
尾联　写喜：岷山千里雪　三军尽开颜
不怕困难　藐视困难　战胜困难　革命乐观主义

阅读链接：课本还选了毛泽东的《菩萨蛮·大柏地》，课后可以读一读，比较两首词的气势。

板书按“总—分—总”梳理：首联总写，颔联、颈联分写山和水，尾联写胜利的喜悦。
