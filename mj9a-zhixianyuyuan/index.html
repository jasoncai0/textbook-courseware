直线与圆的位置关系

巴金在《海上日出》里写太阳“一纵一纵地使劲儿向上升”：先露出小半边脸，再贴着海面，最后完全跳出海面。

把海平线看作一条直线、太阳看作一个圆——直线与圆有几种位置关系？能不能用一个数量来判断？

平移直尺看 $d$ 与 $r$切线的判定与性质三角形的内切圆切线长定理

课本 p63 章节情境（海上日出）。先让学生用自己的话描述三幅画面里太阳与海平线的关系，再引出本课问题。本课内容多，建议 2～3 课时：第 1 课时到第 11 页（位置关系、切线判定与性质），第 2 课时内切圆，第 3 课时切线长。

前情回顾

今天要用到的“旧工具”

$\odot O$ 的半径为 $r$，点 $P$ 到圆心的距离为 $d$：点 $P$ 在圆内 $\Leftrightarrow d<r$；在圆上 $\Leftrightarrow d=r$；在圆外 $\Leftrightarrow d>r$。

直线与圆的三种关系，正是“垂足 $D$ 与圆”的三种关系。

直线外一点到这条直线的垂线段的长度，叫做点到直线的距离；垂线段最短。

圆心到直线的距离 $d$；反证法证明“切线垂直于半径”。

角平分线上的点到角两边的距离相等；角的内部到角两边距离相等的点在角的平分线上。

找三角形内切圆的圆心（内心）。

直径所对的圆周角是直角；两个直角三角形斜边、直角边对应相等则全等（HL）。

判定切线（例 2）；证明切线长相等。

上一课（2.4）研究了圆中的角；本课把目光移到圆外：一条直线和一个圆，会有几种位置关系？

第 1 张卡是本课的“模板”：点与圆的位置关系用 d 与 r 比较，本课直线与圆的关系也用 d 与 r 比较，只是 d 换成了“圆心到直线的距离”。

操作 · 思考

平移直尺：公共点个数怎样变化？

平移直线：半径 $r$：

先在纸上画一个圆，再将一把直尺在纸上平移．把直尺的边缘看作一条直线 $l$．

圆心到 $l$ 的距离 $d$ 半径 $r$ 公共点个数 $d$ 与 $r$

小明：直线与圆的公共点的个数有变化．小丽：圆心到直线的距离也有变化．$d$ 越来越大，公共点从 2 个变成 1 个，再变成 0 个；恰好 1 个时，$d=r$．

课本 p63 操作与思考。拖滑块让直线从穿过圆心一直平移到圆外，学生观察两个量：公共点个数（几何）和 d（数量）。拖到 d 与 r 很接近时会自动吸附到 d = r（只有一个公共点）。再改半径 r 重复，说明结论与 r 的具体大小无关。

概念 · 结论

相交、相切、相离

定义（课本 p64）

直线与圆有两个公共点时，叫做直线与圆相交；有唯一公共点时，叫做直线与圆相切，这条直线叫做圆的切线，这个公共点叫做切点；没有公共点时，叫做直线与圆相离．

（1）相交：$OD<r$

（2）相切：$OD=r$

（3）相离：$OD>r$

结论

如果 $\odot O$ 的半径为 $r$，圆心 $O$ 到直线 $l$ 的距离为 $d$，那么
直线 $l$ 与 $\odot O$ 相交 $\Leftrightarrow d<r$；
直线 $l$ 与 $\odot O$ 相切 $\Leftrightarrow d=r$；
直线 $l$ 与 $\odot O$ 相离 $\Leftrightarrow d>r$．

直线 $l$ 与 $\odot O$ 的三种位置关系，实质上就是垂足 $D$ 与 $\odot O$ 的三种位置关系：$D$ 在圆内、圆上、圆外．“$\Leftrightarrow$”表示从左边可以推出右边，从右边也可以推出左边．

课本 p64 定义、图 2-37 与结论框。两种判断方法：数公共点（定义）、比较 d 与 r（数量）。强调 d 是“圆心到直线的距离”，要先作垂线段。

例 1

先求 $d$，再和 $r$ 比

已知 $\angle BAC=45^\circ$，点 $O$ 在 $AC$ 上，且 $AO=4$，以点 $O$ 为圆心、$r$ 为半径画圆．根据下列 $r$ 的值，判断 $AB$ 所在直线与 $\odot O$ 的位置关系：（1）$r=2$；（2）$r=2\sqrt2$；（3）$r=3$．

解：过点 $O$ 作 $OD\perp AB$，垂足为 $D$．在 $\text{Rt}\triangle AOD$ 中，

∵$\angle A=45^\circ$，∴$\angle AOD=\angle A$，$OD=AD$．

又∵$OD^2+AD^2=AO^2$，$AO=4$，∴$2OD^2=16$，$OD=2\sqrt2$，

即圆心 $O$ 到 $AB$ 所在直线的距离 $d=2\sqrt2$．

（1）当 $r=2$ 时，$d>r$，$AB$ 所在直线与 $\odot O$ 相离；

（2）当 $r=2\sqrt2$ 时，$d=r$，$AB$ 所在直线与 $\odot O$ 相切；

（3）当 $r=3$ 时，$d<r$，$AB$ 所在直线与 $\odot O$ 相交．

课本 p65 例 1、图 2-38。解题顺序：作垂线段 → 求 d（等腰直角三角形 + 勾股定理）→ 比较 d 与 r。$2\sqrt2\approx2.83$，所以 2 < 2√2 < 3。左图按 AO = 4、∠A = 45° 精确作出，点按钮切换三个 r。

思考与探索 · 性质

切线一定垂直于半径吗？

图 2-42：假设 $l$ 与 $OD$ 不垂直，过 $O$ 作 $OD'\perp l$（示意：$D'$ 是假设出来的点）

如图 2-41，直线 $l$ 是 $\odot O$ 的切线，切点为 $D$．直线 $l$ 与半径 $OD$ 有怎样的位置关系？我们用反证法证明 $l\perp OD$．

假设直线 $l$ 与 $OD$ 不垂直，过圆心 $O$ 作 $OD'\perp l$，垂足为 $D'$．反设结论不成立
推理因为 $l$ 与 $\odot O$ 相切，圆心 $O$ 到 $l$ 的距离 $OD'$ 等于半径，点 $D'$ 在 $\odot O$ 上．相切 $\Rightarrow d=r$
矛盾这样，直线 $l$ 与 $\odot O$ 有两个公共点 $D$、$D'$，与“直线 $l$ 与 $\odot O$ 相切”矛盾．相切只有一个公共点
结论所以 $l\perp OD$．假设不成立

结论（课本 p67）

圆的切线垂直于经过切点的半径．

课本 p66–67 思考与探索、图 2-41、2-42。反证法三步：反设 → 推出矛盾 → 肯定结论。图 2-42 是“假设”画出来的示意图，实际上 D′ 不存在——这正是要推出的矛盾。对比上一页：上一页“垂直 ⇒ 切线”（判定），这一页“切线 ⇒ 垂直”（性质）。

例 2

判定切线：证垂直

图 2-43

$A$ 已经是半径 $OA$ 的外端，只要证 $AD\perp AB$，即 $\angle CAD+\angle BAC=90^\circ$．

如图 2-43，$\triangle ABC$ 是 $\odot O$ 的内接三角形，$AB$ 是 $\odot O$ 的直径，$\angle CAD=\angle ABC$．判断直线 $AD$ 与 $\odot O$ 的位置关系，并说明理由．

解：直线 $AD$ 与 $\odot O$ 相切．

∵$AB$ 是 $\odot O$ 的直径，∴$\angle ACB=90^\circ$（）．

∴$\angle ABC+\angle BAC=90^\circ$．

又∵$\angle CAD=\angle ABC$，∴$\angle CAD+\angle BAC=90^\circ$，

即 $AD\perp AB$．

∴直线 $AD$ 与 $\odot O$ 相切（）．

课本 p67 例 2。用判定定理要检查两个条件：经过半径外端（A 在圆上，OA 是半径）+ 垂直于这条半径。图按 ∠CAD = ∠ABC 精确作出（AD 竖直、AB 水平）。

例 3

已知切线：连半径得垂直

图 2-44（按 $\angle BAC=70^\circ$、$AD$ 平分 $\angle BAC$ 精确作出）

已知 $DE$ 是切线，切点 $D$——连接 $OD$，得 $DE\perp OD$；再证 $OD\parallel AC$．

如图 2-44，$AB$ 是 $\odot O$ 的直径，弦 $AD$ 平分 $\angle BAC$，过点 $D$ 的切线交 $AC$ 于点 $E$．$DE$ 与 $AC$ 有怎样的位置关系？为什么？

解：$DE$ 与 $AC$ 互相垂直．连接 $OD$．

∵$OD=OA$，∴$\angle ODA=\angle OAD$（）．

又∵$\angle OAD=\angle CAD$，∴$\angle ODA=\angle CAD$．

∴$OD\parallel AC$（）．

∵$DE$ 是 $\odot O$ 的切线，

∴$DE\perp OD$（），即 $\angle ODE=90^\circ$．

于是，$\angle DEA=90^\circ$，$DE\perp AC$．

课本 p67 例 3。最后一步由 OD ∥ AC 得 ∠DEA = 180° − ∠ODE = 90°（两直线平行，同旁内角互补）。对比例 2：例 2 是“证切线”（用判定），例 3 是“已知切线”（用性质）。常用辅助线：见切点，连半径。

思考与探索 · 作图

作三角形的内切圆

三个顶点都能拖动；作图结果随之更新

小明：圆心到三角形的三边的距离相等．小丽：圆心在三角形的内角平分线上．

  1. 分别作 $\angle ABC$、$\angle ACB$ 的平分线 $BM$、$CN$，$BM$ 与 $CN$ 的交点为 $O$．
  2. 过点 $O$，作 $OD\perp BC$，垂足为 $D$．
  3. 以点 $O$ 为圆心，$OD$ 为半径作 $\odot O$．$\odot O$ 就是所求作的圆．

定义（课本 p69）

与三角形各边都相切的圆叫做三角形的内切圆．内切圆的圆心叫做三角形的内心，这个三角形叫做圆的外切三角形．

内心：三条角平分线的交点，到三边距离相等；外心（2.3）：三边垂直平分线的交点，到三顶点距离相等．

课本 p69 作法表与图 2-46。为什么只作两条角平分线？O 在 ∠B 的平分线上，到 AB、BC 距离相等；在 ∠C 的平分线上，到 BC、CA 距离相等——所以到三边距离都相等，也就在 ∠A 的平分线上。拖动顶点验证：O 永远在三角形内部。

例 4

内切圆与角

图 2-47（按 $\angle B=60^\circ$、$\angle C=70^\circ$ 精确作出）

$\angle EDF$ 是 $\odot O$ 的圆周角，它等于圆心角 $\angle EOF$ 的一半；$\angle EOF$ 在四边形 $AFOE$ 中求．

如图 2-47，$\odot O$ 是 $\triangle ABC$ 的内切圆，切点分别为 $D$、$E$、$F$，$\angle B=60^\circ$，$\angle C=70^\circ$．求 $\angle EDF$ 的度数．

解：连接 $OE$、$OF$．在 $\triangle ABC$ 中，

$\angle A=180^\circ-(\angle B+\angle C)=180^\circ-(60^\circ+70^\circ)=50^\circ$．

∵$\odot O$ 是 $\triangle ABC$ 的内切圆，

∴$AB\perp OF$，$AC\perp OE$（）．

在四边形 $AFOE$ 中，$\angle EOF=360^\circ-(\angle A+\angle AFO+\angle AEO)$

$\qquad\qquad\ \ =360^\circ-(50^\circ+90^\circ+90^\circ)=130^\circ$，

∴$\angle EDF=\dfrac12\angle EOF=65^\circ$（）．

课本 p69–70 例 4。综合了三课的知识：三角形内角和、切线的性质、圆周角定理。规律：∠EDF = 90° − ½∠A，可让学生换一组角验证。

例 5 · 练习

切线长定理的应用

如图 2-51，在以点 $O$ 为圆心的两个同心圆中，大圆的弦 $AB$、$AC$ 分别与小圆相切于点 $D$、$E$．$AB$ 与 $AC$ 相等吗？为什么？

解：$AB$ 与 $AC$ 相等．连接 $OD$、$OE$．

∵$AB$、$AC$ 是小圆的两条切线，切点分别为 $D$、$E$，

∴$AD=AE$（），$AB\perp OD$，$AC\perp OE$（）．

又∵$AB$、$AC$ 是大圆的弦，$OD\perp AB$，$OE\perp AC$，

∴$AB=2AD$，$AC=2AE$（）．∴$AB=AC$．

*练习 1（p72）　$AB$、$AC$、$BD$ 是 $\odot O$ 的切线，切点分别为 $P$、$C$、$D$．若 $AB=5$，$AC=3$，求 $BD$ 的长．

提示从 $A$ 出发的两条切线长：$AP=AC$；从 $B$ 出发的：$BP=BD$．
完整解答$AP=AC=3$，$BP=AB-AP=5-3=2$，$BD=BP=2$．

课本 p72 例 5、练习 *1。例 5 同时用了切线长定理和垂径定理。“拓展与延伸”：连接 DE、BC，DE ∥ BC 且 DE = ½BC（三角形中位线），可作课后思考。

小结

知识 · 方法 · 思想

知识

相交 $\Leftrightarrow d<r$；相切 $\Leftrightarrow d=r$；相离 $\Leftrightarrow d>r$。

切线：判定（过半径外端且垂直于半径）、性质（垂直于过切点的半径）、切线长相等；内切圆、内心。

方法

有公共点：连半径，证垂直；没给公共点：作垂线，证 $d=r$。

见切点，连半径，得直角。

思想

用数量 $d$ 与 $r$ 的大小刻画“形”的位置关系。

类比点与圆的位置关系；用反证法证明切线的性质。
