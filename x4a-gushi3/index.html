故事二则

扁鹊治病据《韩非子·喻老》纪昌学射据《列子·汤问》
找出表示故事发展先后顺序的词句简要复述两个故事交流明白的道理

略读课文，围绕阅读提示：默读课文，找出表示故事发展先后顺序的词句，简要复述这两个故事，再和同学交流从中明白的道理。“扁鹊”读 biǎn què，“纪昌”的“纪”读 jǐ。

扁鹊治病皮肤上有点儿小病

有一天，名医扁鹊去拜见蔡桓侯。扁鹊在蔡桓侯身边站了一会儿，说：“据我看来，您皮肤上有点儿小病。要是不治，恐怕会向体内发展。”

蔡桓侯“我的身体很好，什么病也没有。”

扁鹊走后，蔡桓侯对左右的人说：“这些做医生的，总喜欢给没有病的人治病。医治没有病的人，才容易显示自己的高明！”

黄色的词是表示先后顺序的词，读的时候留意。蔡桓侯不但不信，还觉得扁鹊是想显示自己的高明。

扁鹊治病病越来越重

过了十天，扁鹊又来拜见蔡桓侯，说道：“您的病已经发展到皮肉之间了，要是不治还会加深。”蔡桓侯听了很不高兴，没有理睬他。扁鹊只好退了出去。

十天后，扁鹊再一次来拜见，对蔡桓侯说：“您的病已经发展到肠胃里，再不治会更加严重。”蔡桓侯听了非常不高兴。扁鹊连忙退了出去。

又过了十天，扁鹊老远望见蔡桓侯，只看了几眼，就掉头跑了。……扁鹊解释道：“……现在病已经深入骨髓，所以我不再请求给他医治！”

五天之后，蔡桓侯浑身疼痛，派人去请扁鹊给他治病。扁鹊早知道蔡桓侯要来请他，几天前就跑到秦国去了。不久，蔡桓侯病死了。

蔡桓侯的反应：很不高兴 → 非常不高兴；扁鹊：只好退了出去 → 连忙退了出去 → 掉头跑了。扁鹊为什么跑？下一页看看病是怎样一步步加重的。

扁鹊治病 · 阅读提示

病一步步往里走：点一点时间

表示先后顺序的词句：有一天 → 过了十天 → 十天后 → 又过了十天 → 五天之后 → 不久。顺着它们，故事一步一步往前走。

阅读提示：找出表示故事发展先后顺序的词句。每点一个时间，病就往里走一层；看右边：还能治吗？蔡桓侯怎么做的？最后一次扁鹊为什么“掉头跑了”？

纪昌学射先练眼力

飞卫是一名射箭能手。有个叫纪昌的人，想学习射箭，就去向飞卫请教。

开始练习的时候，飞卫对纪昌说：“你要想学会射箭，首先应该下功夫练眼力。你要牢牢地盯住一个目标，不能眨眼！”

纪昌回家之后，就开始练习起来。妻子织布的时候，他躺在织布机下面，睁大眼睛，死死盯住织布机的踏板。

两年以后，纪昌的本领练得相当到家了——就是锋利的锥尖要刺到眼角了，他的眼睛也不眨一下。

学射箭，飞卫却先让他练眼力。织布机的踏板一上一下，纪昌一盯就是两年。“相当到家”：本领练得很好了。

纪昌学射把小的看大

纪昌对自己的成绩感到很满意，以为练得差不多了，就再次去拜见飞卫。飞卫对他说：“……你要练到把极小的东西看得很大，把模糊难辨的东西看得很清楚，那时候再来见我。”

纪昌记住了飞卫的话，回到家里，又开始练习起来。他用一根牛尾毛拴住一只虱子，把它吊在窗口，然后每天站在虱子旁边，聚精会神地盯着它。

那只小虱子，在纪昌的眼里一天天大起来，练到后来，大得竟然像车轮一样。

取得了这样大的进步，纪昌赶紧跑到飞卫那里，报告了这个好消息。飞卫高兴地说：“你就要成功了！”于是，飞卫开始教他怎样开弓，怎样放箭。

后来，纪昌成了百发百中的射箭能手。

纪昌练了两步眼力：先练不眨眼，再练把小的看大。直到眼力练好了，飞卫才教他开弓放箭。

纪昌学射 · 阅读提示

排一排：纪昌是怎样学射箭的？

按故事发展的先后，依次点一点。

表示先后顺序的词句：开始练习的时候 → 两年以后 → 再次去拜见 → 练到后来 → 于是 → 后来。

发现：先练眼力（不眨眼 → 把小的看大），再学开弓放箭。基本功练扎实了，本领才能学成。

阅读提示：找出表示故事发展先后顺序的词句。排对以后，再请学生借这些词把纪昌学射的过程说一遍。

阅读提示

简要复述：抓主要情节，删去细节

① 顺着顺序词：按故事发展的先后讲，一件不漏。

② 删去细节：人物说的长话、做事的具体样子，可以删去或合成一句。

③ 连起来讲：用自己的话，几句话讲完一个故事。

试一试：不看屏幕，借顺序词，把一个故事讲给同桌听，一分钟内讲完。

阅读提示：简要复述这两个故事。点“删去细节”，划掉的是可以省略的内容，高亮的是要讲的主要情节。上一课《西门豹治邺》学过的方法，这里再用一次。

阅读提示

从故事中明白了什么？

先自己想一想，再点一点卡片。

阅读提示：和同学交流你从中明白的道理。答案不唯一，说得有道理就行。扁鹊治病还留下一个成语：讳疾忌医（隐瞒疾病，不愿意医治）。
