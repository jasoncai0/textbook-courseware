九年级上册 · 第四单元 · 第 16 课 · 莫泊桑

我的叔叔于勒

“唉！如果于勒竟在这只船上，
那会叫人多么惊喜呀！”

每个星期日，父亲都说这句“永不变更的话”。后来，于勒真的在船上了——

梳理小说情节从不同角度分析人物形象体会叙事视角的作用

从父亲反复说的一句话导入，设下悬念。预习一：画出菲利普夫妇对于勒的不同称呼；预习二：这篇小说的主人公是谁？课文根据几种译本改写，人物都是虚构的法国小人物。

开端 · 盼于勒“全家唯一的希望”

可是每星期日，我们都要衣冠整齐地到海边栈桥上去散步。

父亲“唉！如果于勒竟在这只船上，那会叫人多么惊喜呀！”

父亲的弟弟于勒叔叔，那时候是全家唯一的希望，在这以前则是全家的恐怖。

这封信成了我们家里的福音书，有机会就要拿出来念，见人就拿出来给他看。

果然，十年之久，于勒叔叔没再来信。可是父亲的希望却与日俱增。

“衣冠整齐”与前文“拮据”的生活对照——穷却要体面。“唯一的希望”“全家的恐怖”一句话交代了于勒的两种身份，也埋下了伏笔。“福音书”的比喻带着讽刺：信是一张空头支票。

发展 · 船上吃牡蛎“这个卖牡蛎的怎么这样像于勒？”

父亲忽然看见两位先生在请两位打扮很漂亮的太太吃牡蛎。

父亲“你们要不要我请你们吃牡蛎？”

母亲“我怕伤胃，你只给孩子们买几个好了，可别太多，吃多了要生病的。”

我父亲突然好像不安起来，他向旁边走了几步，瞪着眼看了看挤在卖牡蛎的身边的女儿女婿，就赶紧向我们走来。

“真奇怪！这个卖牡蛎的怎么这样像于勒？”

父亲学“高贵的吃法”，母亲“怕伤胃”其实是怕花钱——虚荣与拮据写在一处。“突然好像不安起来”“脸色十分苍白”：情节陡转，进入高潮。

高潮 · 遇于勒“这是我的叔叔，父亲的弟弟，我的亲叔叔。”

船长“他是个法国老流氓，去年我在美洲碰到他，就把他带回祖国。据说他在勒阿弗尔还有亲属，不过他不愿回到他们身边，因为他欠了他们的钱。……”

母亲“我就知道这个贼是不会有出息的，早晚会回来重新拖累我们的。……”

我看了看他的手，那是一只满是皱纹的水手的手。我又看了看他的脸，那是一张又老又穷苦的脸，满脸愁容，狼狈不堪。

我心里默念道：“这是我的叔叔，父亲的弟弟，我的亲叔叔。”

我给了他十个铜子的小费。他赶紧谢我：“上帝保佑您，我的年轻的先生！”

积累拓展四第 2 句：三次同义反复，层层强调血缘关系——越强调“亲”，越反衬出父母的“不认”。“我”的同情与小费，和母亲“你简直是疯了”的反应形成对照。

结局 · 躲于勒“以免再遇见他”

母亲“你简直是疯了！拿十个铜子给这个人，给这个流氓！”

后来大家都不再说话。

在我们面前，天边远处仿佛有一片紫色的阴影从海里钻出来。那就是哲尔赛岛了。

我们回来的时候改乘圣玛洛船，以免再遇见他。

积累拓展四第 3 句：“以免再遇见他”冷冷一句收束全文，亲情彻底让位于金钱。“紫色的阴影”是景，也是一家人此刻阴郁的心情。

预习一 · 本课独有

菲利普夫妇对于勒：骂 → 赞 → 盼 → 骂 → 躲

按 → 让称呼一个个出现；点圆点看原文依据。

发现：叠加“于勒的钱”这条虚线——两条线几乎重合！态度跟着钱走：有钱是“好心的于勒”，没钱是“这个贼”。这就是菲利普夫妇的势利与冷酷，也是那个社会“金钱至上”的人情。

预习一 + 思考探究一的“心理”角度。先请学生在课文里画出各种称呼，再按 → 对照。第 7 步叠加“钱”的虚线，是本页的关键：不要急着骂菲利普夫妇，也可以讨论他们的“拮据”和“体面”——他们也是可怜的小人物。

思考探究一

同一个故事，四个角度梳理情节

小结：故事围绕“态度变化”展开，曲折而集中；四个角度看的都是同一条线——于勒的贫富决定了一家人的态度。

思考探究一。按 → 依次切换四个角度（也可直接点按钮）。可以先分组，每组负责一个角度，用四个短语梳理，再与屏幕对照。

思考探究二

于勒是一个什么样的人？——不止一面

糟蹋钱的浪子行为不正，吃光遗产，还占用了哥哥的那一份
有良心的人？写信说要赔偿损失；“我发了财就会回勒阿弗尔的”
落魄的老水手又老又脏，满脸皱纹，眼光始终不离开手里的活儿
有自尊的穷人“他不愿回到他们身边，因为他欠了他们的钱”

讨论：于勒既可恨又可怜。他是被金钱社会抛弃的人，也是小说的一面镜子——照出了菲利普夫妇。那么，谁是小说的主人公？（预习二）

思考探究二 + 预习二。于勒在小说中几乎没有正面出场、只说了几句话，却是全篇的线索人物。关于主人公，可以有不同看法：菲利普夫妇（态度变化是主线）、于勒（线索人物）、若瑟夫（叙述者，与父母对照），言之有据即可。

思考探究三

换一双眼睛讲“付牡蛎钱”：有什么不同？

孩子的视角：若瑟夫回忆少年往事，看得真、说得少——天真善良的眼光与大人的冷漠形成对照，“真实感”和“讽刺味”都更强。

思考探究三。后两种是示例改写，不是原文，提醒学生注意。可以请学生自己选一个人物（父亲、二姐、女婿、于勒）改写同一段，再比较。

积累拓展四

揣摩三句话

唉！如果于勒竟在这只船上，那会叫人多么惊喜呀！

（人物怎样的心理？）把发财的希望全寄托在于勒身上；“永不变更”的重复，写出盼望之切，也为后文“遇于勒”埋下伏笔，形成讽刺。

我心里默念道：“这是我的叔叔，父亲的弟弟，我的亲叔叔。”

（为什么三次同义反复？）层层强调血缘，表现“我”的同情与震动，反衬父母的冷酷。

我们回来的时候改乘圣玛洛船，以免再遇见他。

（给你什么感受？）冷漠、心寒。亲兄弟对面不相认，金钱关系代替了亲情。

积累拓展四。先读句子，请学生按括号里的问题说，再按 → 出示参考理解。三句正好对应“盼—遇—躲”。

积累拓展五 · 读写迁移

假如于勒成了百万富翁……

选一个任务，写在右边。

积累拓展五。写作要点：人物性格前后一致（势利），只是方向反过来；语言、动作、神态要有“戏”。第二个任务从于勒的角度写，理解他“可恨又可怜”的一面。

回顾

我的叔叔于勒

情节：盼于勒 → 赞于勒 → 遇于勒 → 躲于勒

称呼：流氓、无赖 → 正直的人 → 好心的于勒 → 这个贼、讨饭的

人物：菲利普夫妇：虚荣、势利、冷酷　｜　于勒：可恨又可怜　｜　若瑟夫：善良、同情

主题：金钱至上，亲情冷漠——小人物的辛酸与悲哀
