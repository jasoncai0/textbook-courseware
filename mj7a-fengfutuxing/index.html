概念

棱柱、棱锥各部分的名称

点上面的按钮，在右边两个图中找一找。

课本 p122

在棱柱、棱锥中，任何相邻两个面的交线叫做棱，相邻两个侧面的交线叫做侧棱．
棱柱的棱与棱的交点叫做棱柱的顶点．
棱锥的各侧棱的公共点叫做棱锥的顶点．
棱柱的侧棱长相等，棱柱的上、下底面是相同的多边形，直棱柱的侧面都是长方形．
棱锥的侧面都是三角形．

“棱”和“侧棱”：侧棱只指两个侧面的交线；底面上的边也是棱，但不是侧棱。6 条侧棱；棱一共 $6+6+6=18$ 条。

课本 p122 图 5-4（六棱柱、五棱锥）。逐个按钮点：先“底面”“侧面”，再“棱”“侧棱”，最后“顶点”。注意棱锥的“顶点”在课本里专指各侧棱的公共点；底面多边形的角上的点学生也会叫顶点，可以说明“课本定义的棱锥的顶点是最上面那一个”。

不要一个一个数——想一想它们是怎样组成的。

n 棱柱的面$n+2$2 个底面 + $n$ 个侧面（底面每条边对着一个侧面）
n 棱柱的棱$3n$上底 $n$ 条 + 下底 $n$ 条 + 侧棱 $n$ 条
n 棱柱的顶点$2n$上、下底面各 $n$ 个
n 棱锥面 $n+1$，棱 $2n$，顶点 $n+1$1 个底面 + $n$ 个侧面；底面 $n$ 条 + 侧棱 $n$ 条；底面 $n$ 个 + 顶上 1 个

四棱柱就是长方体：$4+2=6$ 个面，$3\times4=12$ 条棱，$2\times4=8$ 个顶点——和小学学的一样。

这是对课本 p122 概念的延伸练习（课本没有给公式，这里不要求记，要求会“按组成去数”）。先让学生拖到 n = 3、4 自己数，再问 n = 100 怎么办，引出按“上底、下底、侧面”分类计数。

点 · 线 · 面

平的面、曲的面；面面相交得线，线线相交得点

课本 p121–122

桌面、墙面、平静的水面等都给我们以平面的形象．水管、易拉罐的侧面，地球仪的表面等都给我们以曲面的形象．
面与面相交得到线，线与线相交得到点．
几何图形由点、线、面组成．

线有直的也有曲的：圆柱的底面与侧面相交，得到的是曲线（圆）；正方体相邻两个面相交，得到的是直线的一段（棱）。

课本 p121 下半页（教室墙角、城市地图）。墙角：两面墙相交得到一条线，三条线交于一点；地图：两条路相交于路口。先选“平面/曲面”，四种几何体逐个看，再选“线与点”。球最有意思：只有一个曲面，没有棱和顶点。

课本 p123 练一练 2：(1) 围成下列几何体的各个面中，哪些面是平的？哪些面是曲的？(2) 将下列几何体分类，并说明理由．

(1) 平的面、曲的面

①⑤ 的面都是平的；② 球只有一个曲面；③④ 底面是平的，侧面是曲的。

分法一：按“有没有曲面”

{①⑤}：围成它的面都是平面；{②③④}：有曲面。

分法二：按“柱、锥、球”

柱体 {③⑤}，锥体 {①④}，球 {②}。

分类先定标准，同一次分类只用一个标准，做到不重复、不遗漏。

数学实验室

七巧板：用几块拼出正方形、长方形、三角形

用 6 块能拼成三角形吗？拼不成！七巧板拼出的三角形都是等腰直角三角形，面积只能是 1、2、4、8、9、16……（以小三角形面积为 1）；任取 6 块，面积是 12、14 或 15，都不在里面。

课本 p123 数学实验室：(1) 哪些板能拼成正方形、长方形、平行四边形？(2) 用 3 块拼三角形，4 块、5 块、6 块呢？拖动每块中心的橙点移动，点一下某块再按“转 45°”“翻面”；靠近时顶点会自动吸附。拼成后程序用“目标框内每个点恰好被一块盖住”来判断。6 块的结论是拓展，供学有余力的学生思考（三角形的直角边由小三角形的直角边 √2 和斜边 2 组成，面积只能是 a² 或 2b² 的形式）。

小结

知识 · 方法 · 思想

知识

常见几何体：圆柱、圆锥、正方体、长方体、球、棱柱、棱锥。

棱柱、棱锥的底面、侧面、棱、侧棱、顶点；几何图形由点、线、面组成。

方法

不管颜色、材料、大小，只看形状。

面、棱、顶点按“上底—下底—侧面”分组数，不重不漏。

思想

先定标准：按有无曲面、按柱锥球……

几何体的表面由一块块平面图形（或曲面）围成。
