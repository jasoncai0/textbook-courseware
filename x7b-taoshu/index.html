一棵小桃树

贾平凹

数一数：作者一共叫了它几次“我的小桃树”？

托物言志物与“我”的命运与《紫藤萝瀑布》比较

自读课。开课就抛出“阅读提示”里的第一个问题：数“我的小桃树”。数的过程就是默读全文的过程；数完再问——为什么这么执着地叫它“我的”？

阅读提示

一共几次“我的小桃树”？

0次

按 → 一次找一处。称呼越执着，感情越深。

为什么偏说“我的”？这棵“野”的、“没出息”的、不美的小桃树，是作者儿时的梦长成的——“我的小桃树”就是另一个“我”。

  1. 我常常想要给我的小桃树写点文章，但却终没有写就一个字来。
  2. 我深深闭了柴门，伫窗坐下，看我的小桃树在风雨里哆嗦。
  3. 爷爷便每天一早喊我们从屋里一盆一盆端出来……却从来不想到我的小桃树。
  4. 天黑的时候，在窗下坐着，一抬头，却看见我的小桃树了；……
  5. 我深深懊丧对不起我的奶奶，对不起我的小桃树了。
  6. 可我的小桃树，一颗“仙桃”的种子，却开得太白了，太淡了……
  7. 雨还在下着，我的小桃树千百次地俯下身去，又千百次地挣扎起来……

课文中共 7 次（不算“那土院里的小桃树”“可怜的小桃树”“啊，小桃树啊”等）。数的时候顺便注意每一次出现在什么情境：写作的冲动、风雨、被冷落、重逢、愧疚、花开、挣扎——每次都牵着作者的心。

读课文 · 风雨里的小桃树第 2 段

今天的黄昏，雨下得这般大，使我也有些吃惊了。

那雨却下得大了，全不是春的温柔，一直下了一个整天。我深深闭了柴门，伫窗坐下，看我的小桃树在风雨里哆嗦。

纤纤的生灵，枝条已经慌乱，桃花一片一片地落了，大半陷在泥里，三点两点地在黄水里打着旋儿。

啊，它已经老了许多呢，瘦了许多呢，昨日楚楚的容颜全然褪尽了。可怜它年纪太小了，可怜它才开了第一次花儿！

唉，往日多么傲慢的我，多么矜持的我，原来也是个孱头。

旁批：“寻常的情景，不寻常的情感。”一场春雨、一树落花，为什么让作者“千般万般地无奈何”，还骂自己是“孱头”？带着这个疑问往下读——答案在小桃树的“身世”里。

桃树与“我”

两条线，一样的命运

小桃树的处境“我”的心境点一列，看原文

按 → 一步一步往下走，或者直接点任意一列。

本课独有的呈现：两条命运线并排走。课文明写桃树的“身世”（埋核—发芽—被冷落—被拱折—开花—遭风雨—留花苞），暗写“我”的经历（童年的梦—进城—碰壁—奶奶去世—忧伤—重燃希望）。两条线起伏几乎一致：桃树就是另一个“我”。

读课文 · 一个欲绽的花苞第 12—13 段

雨还在下着，我的小桃树千百次地俯下身去，又千百次地挣扎起来，一树的桃花，一片，一片，湿得深重，像一只天鹅，羽毛渐渐剥脱，变得赤裸的了，黑枯的了。

然而，就在那俯地的刹那，我突然看见那树的顶端，高高的一枝儿上，竟还保留着一个欲绽的花苞，嫩黄的，嫩红的，在风中摇着，抖着满身的雨水，几次要掉下来了，但却没有掉下去，

像风浪里航道上的指示灯，闪着时隐时现的嫩黄的光，嫩红的光。

我心里稍稍有些安慰了。啊，小桃树啊！我该怎么感激你？你到底还有一朵花呢，明日一早，你会开吗？

旁批：“‘我’的情感在这里来了一个转折，你读出来了吗？”“然而”是转折点：从忧伤到安慰。花苞“几次要掉下来了，但却没有掉下去”——这正是作者在挫折中不肯放弃的梦。

跟着旁批读

作者仅仅在写花吗？

自读课的旁批是阅读的路标。先让学生自己回答，再点“我的理解”对照。重点是第 3 条：“作者仅仅在写花吗？”——白、淡、薄、苦涩地笑的花，正是作者失意时的自己。

阅读提示 · 比较阅读

与《紫藤萝瀑布》比一比

紫藤萝瀑布一棵小桃树
物一树繁盛、辉煌的紫藤萝一棵瘦弱、“没出息”的小桃树
物与人由花及人：花在“我”心上流过物我合一：“我的小桃树”就是另一个“我”
线索眼前的花 → 回忆的花 → 眼前的花风雨中的桃树 → 桃树的身世 → 风雨中的花苞
情感悲痛 → 宁静、喜悦 → 振作忧伤 → 愧疚 → 安慰、希望
志生命的长河是无止境的在挫折中坚守自己的梦
相同都是托物言志；都写了物的今昔变化；都由物引发对人生的思考，语言细腻、富有感情。

阅读提示最后一问。单元导语建议“运用比较的方法阅读”。先让学生分小组填，再逐行出示。不必追求标准答案，言之有据即可。
