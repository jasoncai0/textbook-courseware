想一想

为什么外项积一定等于内项积？

如果用字母表示比例的四个项，即 $a:b=c:d$，写成分数形式：

$\dfrac ab=\dfrac cd$比例的分数形式
$\dfrac ab\times bd=\dfrac cd\times bd$等式两边同时乘 $bd$（等式的性质）
$a\times d=b\times c$约分：左边约去 $b$，右边约去 $d$

比例的基本性质

在比例里，两个外项的积等于两个内项的积。

如果 $a:b=c:d$，那么 $a\times d=b\times c$。

写成分数形式，把等号两端的分子、分母交叉相乘：$6\times2=3\times4$。

课本 p39 用字母表示规律、“把比例写成分数形式交叉相乘”。第 2 步是五下等式的性质，约分时 b、d 都不为 0（比的后项不能是 0）。如学生理解有困难，可以只用 6/3 = 4/2 的具体数验算一遍。

试一试

应用比例的基本性质，判断能否组成比例

$3.6:1.8$ 和 $0.5:0.25$

$3.6\times0.25=$

$1.8\times0.5=$

外项积等于内项积：$3.6:1.8=0.5:0.25$。

$\frac13:\frac14$ 和 $18:24$

$\frac13\times24=$

$\frac14\times18=$

$8\ne4.5$，外项积不等于内项积，不能组成比例。

先把两个比写成“$\square:\square=\square:\square$”，再算外项积和内项积；相等就能组成比例。比值是小数、分数时，这种方法往往更方便。

课本 p39 试一试。第二组如果求比值：1/3∶1/4 = 4/3，18∶24 = 3/4，也不相等，两种方法结果一致。

练习七 · 1、2

应用比例的基本性质判断

1. 哪几组的两个比可以组成比例？

$14:21$ 和 $6:9$

$14\times9=126=21\times6$

$\dfrac34:\dfrac1{10}$ 和 $\dfrac{15}2:1$

$\dfrac34\times1=\dfrac1{10}\times\dfrac{15}2=\dfrac34$

$9:12$ 和 $12:16$

$9\times16=144=12\times12$

$1.4:2$ 和 $7:10$

$1.4\times10=14=2\times7$

2. 下面哪几组中的四个数可以组成比例？

5，7，15 和 21

$5\times21=7\times15$：$5:7=15:21$

2，4，6 和 8

两两相乘：16 与 24、12 与 32、8 与 48，都不相等

4，3，$\dfrac13$ 和 $\dfrac14$

$4\times\dfrac14=3\times\dfrac13=1$

$\dfrac35$，$\dfrac15$，9 和 3

$\dfrac35\times3=\dfrac15\times9=\dfrac95$

课本 p41 练习七第 1、2 题。第 2 题“四个数组成比例”的方法：试着把四个数两两相乘，找到相等的两个积，再写成比例（积相等的一对作外项，另一对作内项）。

小结

外项积 = 内项积

比例的四个数叫作项；两端是外项，中间是内项。在比例里，两个外项的积等于两个内项的积。

判断能否组成比例：求比值，或者算外项积、内项积；写成分数形式就是交叉相乘。

从例子中发现规律 → 写更多例子验证 → 用字母说明道理。
