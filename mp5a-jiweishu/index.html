积的位数与积的近似值

小明在阳台上摆了一个花架，底面是边长 0.28 米的正方形。

按整数乘，$28\times28=784$，可积要有四位小数，784 只有三个数字——小数点往哪儿点？

数位数不够补 0四舍五入积的近似值

课本 p66 例 8 的情境。先让学生口头列式 0.28 × 0.28，再抛出矛盾：“数字不够数怎么办？”不急着回答，进入新课。

前情回顾

小数乘小数，我们是怎样算的？

$2.4\times0.8=1.92$

先按整数乘：$24\times8=192$；两个因数一共有两位小数，就从积的右边起数出两位，点上小数点。

今天还用这个方法，只是数字可能“不够数”。

小数点向左移动一位、两位、三位……小数就缩小到原数的 $\frac1{10}$、$\frac1{100}$、$\frac1{1000}$……

$784\to0.784\to0.0784$：位数不够时，用 0 补足。

点小数点时，前面补 0 的道理就在这里。

$3.846\approx3.85$

保留两位小数，看千分位：满 5 进 1，不满 5 舍去（“四舍五入”法）。

例 8 · 动手数

从积的右边起，一位一位数出小数点的位置

按“数一位”，小数点从积的最右边往左跳。

我们的发现

在积里点小数点时，位数不够的，在前面用 0 补足。

本课核心操作。每按一次“数一位”，小数点向左跳过一个数字，计数加 1；数字用完了还没数够，就在前面补一个粉色的 0。数够后，整数部分没有数字的写 0（如 0.0784）。第 3 题 1.05 × 0.06 先得 0.0630，再按“去掉末尾的 0”——小数末尾的 0 可以去掉（小数的性质）。让学生先猜每题要补几个 0，再按。

辨一辨

下面的计算对吗？先判断，再说理由

两个因数一共有两位小数，积也要有两位：$2.5\times3.5=8.75$，不是 87.5。

要先点小数点、再去掉末尾的 0：$7380\to73.80=73.8$。先划掉 0 再数位数，就点错了。

一共有 $1+2=3$ 位小数：$823\times4=3292$，积是 3.292，不是 32.92。

点小数点要数“两个因数一共的小数位数”，而且要在去 0 之前数。

课本 p67 练习十二第 2 题。三个竖式按课本的错误写法由代码排出。先举手表决，再请学生点。第 2 题最容易错：整数积 7380 的末尾 0 也要算进位数里。

例 9 · 积的近似值

去年大约收入多少万元？

王大伯家前年收入 3.18 万元，去年的收入是前年的 1.6 倍。去年大约收入多少万元？（得数保留两位小数）

$3.18\times1.6=5.088$，有三位小数。保留两位小数，要看哪一位？　看千分位上的 8。

千分位上是 8，满 5，向百分位进 1：

$3.18\times1.6\approx$

答：去年大约收入 5.09 万元。

课本 p66 例 9。竖式按“下一步”：部分积 → 整数积 5088 → 点小数点 5.088 → 框出千分位的 8（课本里的虚线框）。数轴把 5.08 到 5.09 平均分成 10 份，5.088 在中点 5.085 右边，所以更接近 5.09——这就是“满 5 进 1”的道理。
