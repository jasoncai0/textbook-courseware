认识正数和负数

同一天，三亚的最低气温是零上 20℃，哈尔滨的最低气温是零下 20℃。

都是“20℃”，意思一样吗？怎样写，别人一看就知道是零上还是零下？

读温度计零上、零下海拔高、低正数和负数

课本 p1 例 1 的情境。先让学生说说冬天的南方和北方有什么不同。抛出问题：两个城市都是“20℃”，只写一个 20，能区分开吗？——需要一种新的数。

前情回顾

学负数之前，先想想这三件事

0 可以表示一个也没有；在直尺上，0 还表示起点。

温度计上的 0℃，也是一个“分界线”。

看液柱顶端对着的刻度；每一大格是 10℃，每一小格是 2℃。

例 1 要读出三个城市的最低气温。

零上和零下、高于海平面和低于海平面……意思正好相反。

意思相反的两种量，今天用“+”“−”来区分。

今天的问题：零上 20℃ 和零下 20℃，能不能用不同的数表示出来？

第 2 张卡：课本里的温度计每一大格 10℃、每一小格 2℃，本课的温度计按同样的刻度画。请学生说说生活中还有哪些“意思相反”的说法（上升 / 下降、存入 / 取出……）。

温度计显示的是某一天 3 个城市的最低气温

从图中你能知道些什么？

动手调一调

“+20℃”和“−20℃”的含义有什么不同？

上下拖动红色液柱

+20℃ 和 −20℃ 有什么不同？　+20℃ 在 0℃ 上面 20℃，是零上；−20℃ 在 0℃ 下面 20℃，是零下。离 0℃ 一样远，方向相反。

本课核心互动。请学生上来按任务调温度计：右边读数会同时显示“零上 / 零下”的说法、记法和读法。任务做完后讨论 +20℃ 和 −20℃ 的不同：以 0℃ 为界，一个向上、一个向下。

例 2 · 看图说

珠穆朗玛峰和吐鲁番盆地，比海平面高还是低？

通常，我们规定海平面的平均海拔高度为 0 米。

珠穆朗玛峰比海平面高 8848.86 米，称为海拔 8848.86 米，可以记作 +8848.86 米。

吐鲁番盆地比海平面低 155 米，称为海拔负 155 米，可以记作 −155 米。

左图的高度是按比例画的：155 米和 8848.86 米比，实在太小了，右下角把盆地放大了 20 倍。

课本 p2 例 2。课本的插图是示意图，这里按真实比例画（每 1000 米同样长），珠峰顶在 +8848.86 米，盆地最低处在 −155 米；放大框里同一段按 20 倍画，便于看清。海平面就像温度计上的 0℃：高于它用“+”，低于它用“−”。

概括

什么是正数？什么是负数？

+20、+8848.86、−20、−155……这些数可以分成几类？　带“+”的一类，带“−”的一类。

正数和负数

像 +20、+8848.86 这样的数都是正数（正数前面的“+”可以省略不写），像 −20、−155 这样的数都是负数。

0 是正数还是负数？　0 既不是正数，也不是负数。它是正数和负数的分界（0℃、海平面）。

“+20”和“20”一样吗？　一样。正数前面的“+”可以不写，所以 8、26 也是正数；负数前面的“−”不能省略。

负数 ……　−3　−2　−101　2　3 ……　正数

课本 p2 下半页。定义请全班齐读；重点讨论两个追问：0 的归属、“+”可以省略而“−”不能省略。最后一行先只是直观排列，下一课会把它画成直线（数轴的雏形）。

练习一

生活中的正数和负数

1. 读一读下面的温度，说说哪个是正数，哪个是负数。

水沸腾时的温度是 100℃。

100 前面省略了“+”，是正数。

水结冰时的温度是 0℃。

0 既不是正数，也不是负数。

地球表面的最低气温在南极，可达 −89.2℃。

零下 89.2℃，是负数，读作“负八十九点二”。

2. 用正数或负数表示下面的海拔高度。

中国最大的咸水湖——青海湖，高于海平面 3260 米。
海拔 米

世界最低最咸的湖——死海，低于海平面 422 米。
海拔 米

小结

今天认识了什么新朋友？

正数

+20、+8848.86、8、+103……
“+”可以省略不写

0

既不是正数，也不是负数
是正数和负数的分界

负数

−20、−155、−89.2……
“−”不能省略

零上 / 零下的温度、高于 / 低于海平面的海拔……以 0 为界、意思相反的两种量，可以分别用正数和负数表示。
