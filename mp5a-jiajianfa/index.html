小数加法和减法

文具柜台：钢笔 8 元，笔记本 3.4 元，讲义夹 4.75 元，水彩笔 2.65 元。

小明买 1 个讲义夹，小丽买 1 本笔记本，一共要用多少元？竖式该怎样对齐？

对齐实验竖式一步一步算路线图

课本 p48 例 1 的情境。先让学生估一估：4 元多加 3 元多，一共大约 8 元。这个估计后面用来检验竖式对不对。

前情回顾

算小数加减法，要用到哪些旧知识？

475+34509

相同数位对齐，从个位算起，满十进一。

小数也要相同数位对齐。

7 个 0.1 + 4 个 0.1 = 11 个 0.1 = 1.1

只有计数单位相同的数才能直接相加减。

为什么要“小数点对齐”。

3.4 = 3.40

末尾添 0 或去 0，大小不变。

被减数位数不够时补 0；结果末尾的 0 化简。

今天的问题：4.75 + 3.4，竖式应该“末尾对齐”还是“小数点对齐”？

第 1 张卡的整数竖式 475 + 34 和今天的 4.75 + 3.4 数字一样，正好引出冲突：整数是末尾对齐，小数也能这样吗？

例 1 · 对齐实验

4.75 + 3.4：哪一种算法正确？为什么？

用元、角、分验证

元角分
讲义夹 4.75 元475
笔记本 3.4 元340
合起来7115

11 角 = 1 元 1 角，一共 元。

小数点对齐了，相同数位就对齐了：元对元、角对角、分对分，计数单位相同才能相加。

课本 p48 两个小精灵的算法。先切到“末尾对齐”：表头标出每一列的数位，3.4 的“3”跑到了十分位，“4”跑到了百分位——3 个一被当成了 3 个 0.1，所以得 5.09，比估计的 8 元差太多。再切回“小数点对齐”，得 8.15，和用元角分算的一致。

例 1 · 竖式

一列一列算：从最低位算起

(1) $4.75+3.4=$ （元）

(2) 小明比小丽多用多少元？
$4.75-3.4=$ （元）

试一试

小明和小芳一共：$4.75+2.65=$ （元）

小芳比小明少：$4.75-2.65=$ （元）

你能把计算的结果化简吗？　7.40 = 7.4，2.10 = 2.1：得数末尾的 0 一般去掉。

课本 p48 例 1(1)(2) 和试一试。左边竖式点“算下一列”：从百分位开始，一列一列算，进位用小 1 标出，最后在得数里点上小数点（和横线上面的小数点对齐）。3.4 的百分位上没有数，看作 0（灰色虚框）。试一试的两题在左边也可以选。

想一想

小数加减法和整数加减法，有什么相同的地方？

相同

都要把相同数位对齐；都从最低位算起；满十进一、退一当十。

要注意

小数要小数点对齐（这样相同数位才对齐）；得数里的小数点要和横线上的小数点对齐；得数末尾有 0 的，一般要化简。

  1. 小数点对齐（也就是相同数位对齐）；
  2. 按整数加、减法的方法计算；
  3. 得数里对齐横线上的小数点，点上小数点；能化简的化简。

课本 p49 上方的问题，先让学生和同桌说，再出示。强调：整数的“末尾对齐”其实也是“个位对齐”，本质都是相同数位对齐。

例 2

1 本笔记本比 1 支水彩笔贵多少元？

$3.4-2.65=$ （元）

被减数的百分位上没有数，为什么可以看作 0？　根据小数的性质：3.4 = 3.40，在末尾添 0 大小不变。

试一试：1 支水彩笔比 1 支钢笔便宜多少元？
$8-2.65=$ （元）　8 = 8.00，十分位和百分位都看作 0。

小数加、减法的验算方法与整数相同：$0.75+2.65=3.4$ ✓

课本 p49 例 2 和试一试。左边竖式选“3.4 − 2.65”，点“算下一列”：百分位 0 − 5 不够减，从十分位退 1（退位点），10 − 5 = 5……注意得数的整数部分是 0，要写 0。再选“8 − 2.65”看连续退位。最后选“验算”用加法检验。

小结

小数点对齐，就是数位对齐

小数点对齐相同数位对齐
然后
从最低位算起满十进一 · 退一当十
最后
点上小数点对齐横线上的小数点，能化简就化简

空着的数位看作 0（小数的性质）：3.4 − 2.65 → 3.40 − 2.65；8 − 2.65 → 8.00 − 2.65。
