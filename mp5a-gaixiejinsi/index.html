改写和求近似数

地球和月球之间的平均距离大约是 384400 千米，地球和太阳之间的平均距离大约是 149600000 千米。

这么长的数，读写都不方便。能不能写得简短一些？

小数点搬家用“万”“亿”作单位四舍五入数轴

课本 p42 例 8 的情境。先让学生读一读这两个数（三十八万四千四百、一亿四千九百六十万），感受“数大了读写麻烦”。

前情回顾

四年级学过的“万”“亿”和“≈”

380000 = 38 万

整万数：去掉末尾 4 个 0，添上“万”字。

384400 不是整万数，怎么办？

384400 ≈ 38 万

省略万位后面的尾数：看千位，4 < 5，舍去。

小数也用“四舍五入”法求近似数。

38.4400 = 38.44

小数末尾的 0 去掉，大小不变。

改写后把小数末尾的 0 去掉。

注意区分：“=”表示大小完全相等；“≈”表示近似，大小变了一点点。

第 2 张卡的“≈”和第 1 张卡的“=”放在一起对比：今天的改写用“=”，求近似数用“≈”。

例 8 · 小数点搬家

把 384400 改写成用“万”作单位的数

想法 1：这个数比 380000 多一些，用“万”作单位，整数部分是 38。

想法 2：384400 里有 38 个万和 4400 个一，4400 个一是 0.44 万。

课本 p42 例 8(1)。整数的小数点“藏”在个位的右边。点“改写成用‘万’作单位”：小数点从个位右边搬到万位右边，小数末尾的 0 按小数的性质去掉，最后添上“万”字。数的大小没变，所以用“=”。可以换其他数试一试，再点“亿”。

例 8 · 概括

只要在万位右边点上小数点，并在数的后面添上“万”字。

课本 p42 例 8(2)、试一试和 p43 练一练。做完回到上一页用“小数点搬家”验证 57910000 和 4300000：亿位、千万位上没有数字的，会补上橙色的 0。

例 9 · 求近似数

1.496 亿千米，精确到十分位大约是多少？

课本 p43 例 9。精确到十分位就是保留一位小数：1.496 在 1.4 和 1.5 之间，离谁近？直线上的虚线是“正中间”1.45：点在虚线右边就离 1.5 近（看百分位 9 ≥ 5，进一）；在左边就离 1.4 近（舍去）。点的位置按数值精确画出。再切换“精确到百分位”：1.496 在 1.49 和 1.50 之间。

例 9 · 想一想

近似数 1.50 末尾的“0”能去掉吗？

近似数 1.5：原来的数在哪个范围？　大于或等于 1.45，小于 1.55——范围宽。

近似数 1.50：原来的数在哪个范围？　大于或等于 1.495，小于 1.505——范围窄，更精确。

1.5 是精确到十分位的近似数，1.50 是精确到百分位的近似数，1.50 比 1.5 更精确。所以近似数末尾的 0 不能去掉。

课本 p43“想一想”。图中两段彩色范围按数值精确画出：橙色 1.45～1.55（宽 0.1），蓝色 1.495～1.505（宽 0.01）。小数的性质说的是“大小不变”，但近似数的 0 还表示“精确到哪一位”，去掉就不一样精确了。

小结

改写用“=”，求近似数用“≈”

384400 = 38.44 万

在万位（或亿位）右边点上小数点，去掉小数末尾的 0，添上“万”（“亿”）字。

1.496 ≈ 1.50

精确到哪一位，看它的下一位，四舍五入；近似数末尾的 0 不能去掉。

有时两步连着做：149600000 千米 = 1.496 亿千米 ≈ 1.5 亿千米。
