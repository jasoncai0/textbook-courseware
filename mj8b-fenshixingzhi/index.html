八年级下册 · 第10章 分式 · 10.2

分式的基本性质

一列匀速行驶的火车，$t$ h 行驶 $s$ km，$2t$ h 行驶 $2s$ km，…，$nt$ h 行驶 $ns$ km．

$\dfrac st$、$\dfrac{2s}{2t}$、$\dfrac{3s}{3t}$、…、$\dfrac{ns}{nt}$ 都表示这列火车的速度——由此你发现了什么？

基本性质符号变化约分 · 最简分式通分 · 最简公分母

课本 p101“讨论”。请学生说出：同一个速度，写成了不同的分式——分子、分母同乘 n，值不变。这就是本课要研究的“分式的基本性质”，它是后面约分、通分以及分式加减乘除的依据。

前情回顾

今天要用到的旧知识

分数的分子和分母都乘（或除以）同一个不等于 0 的数，分数的值不变：$\dfrac23=\dfrac46$，$\dfrac{12}{18}=\dfrac23$。

类比得到分式的基本性质。

约分：同除以最大公因数；通分：化成以最小公倍数为分母的分数，如 $\dfrac16,\dfrac14\to\dfrac2{12},\dfrac3{12}$。

分式的约分、通分照着做，只是“数”换成了“式”。

提公因式：$ma+mb-mc=m(a+b-c)$；公式法：$a^2-b^2=(a+b)(a-b)$，$a^2-2a+1=(a-1)^2$。

分子、分母是多项式时，先分解因式，才看得出公因式。

分式 $\dfrac AB$ 中，$B$ 是含字母的整式，$B\ne0$；分式的值随字母的取值而变化。

说明“同乘的整式 $C$ 为什么不能为 0”；用代值的方法检验变形对不对。

上一课（10.1）讲到分式的概念、分式的值和“分母不能为 0”。本课先类比分数的基本性质得到分式的基本性质，再用它做约分、通分——五年级的“约分、通分”和七年级下的“因式分解”都要用上，请学生各举一个例子口头复习。

讨论 · 猜想

分式也有类似分数的性质吗？

火车 $t$ h 行驶 $s$ km．下面每个分式都表示它的速度（km/h）：

$\dfrac st=\dfrac{2s}{2t}=\dfrac{3s}{3t}=\cdots=\dfrac{ns}{nt}$

从 $\dfrac st$ 到 $\dfrac{ns}{nt}$，分子、分母发生了什么变化？分子、分母都乘了同一个 $n$。

分数里“同乘的数不能是 0”。分式里同乘的 $n$ 有什么要求？$n\ne0$：若乘 0，分母变成 0，分式无意义。

用 $s=120$、$t=2$ 验证一下：

分式$\dfrac st$$\dfrac{2s}{2t}$$\dfrac{3s}{3t}$$\dfrac{5s}{5t}$
值$\dfrac{120}{2}=60$$\dfrac{240}{4}=60$$\dfrac{360}{6}=60$$\dfrac{600}{10}=60$

猜想

分式的分子和分母都乘（或除以）同一个不等于 0 的整式，分式的值不变。

只试了几组数，能说明“任何时候都成立”吗？下一页换不同的“乘数”多试几组，看看哪里要小心。

课本 p101 开头与“讨论”。先类比分数的基本性质让学生自己说出猜想，再追问“乘的可以是含字母的式子吗？”“乘 0 行不行？”。分式的基本性质课本直接给出，这里用代值实验帮助理解，不作严格证明（它的依据是分数的基本性质：字母取任何使分母不为 0 的值，分式都变成分数）。

实验

分子、分母同乘 $C$：值变不变？

把 $\dfrac ba$ 的分子、分母同乘一个整式 $C$，代入几组 $a$、$b$ 的值比较（精确计算）。

$C=0$ 时怎么样？$\dfrac{b\cdot0}{a\cdot0}=\dfrac00$，每一组都无意义——所以 $C$ 不能是 0。

$C=a-1$ 时，哪一组出了问题？$a=1$ 时 $C=0$，$\dfrac{b(a-1)}{a(a-1)}$ 无意义，而原式 $\dfrac ba=4$——变形后，字母能取的值变少了。

乘的整式 $C$ 可以含字母，但必须 $C\ne0$；在使 $C\ne0$ 的范围内，两个分式的值处处相等。

本页是代值实验：点不同的 C，左表用精确分数计算原式与变形后的式子。先试 2、a、b+1（值都不变），再试 0（全部无意义），最后试 a − 1（a = 1 那一列出问题）。由此理解课本“C 是不等于 0 的整式”这句话：不是可有可无的条件。

性质

分式的基本性质

分式的基本性质（课本 p101）

分式的分子和分母都乘（或除以）同一个不等于 0 的整式，分式的值不变．$$\frac AB=\frac{A\times C}{B\times C},\qquad \frac AB=\frac{A\div C}{B\div C},$$其中 $C$ 是不等于 0 的整式．

与分数的基本性质比，哪里变了？“同一个数”变成了“同一个整式”。

“同一个”是说？分子、分母要乘（除以）相同的式子，只乘一处值就变了。

“不等于 0”是说？乘 0 会使分母为 0；除以 0 没有意义。

它是分式变形的依据：本课的约分、通分，下两课的加减乘除，每一步变形都要靠它。

课本 p101 框内的性质。请学生齐读并圈出三个关键词：都、同一个、不等于 0 的整式。与上一页实验对应：0 不行；a − 1 在 a = 1 时等于 0，用它时要附带 a ≠ 1。

例 1

右边是怎样从左边得到的？

(1) $\dfrac ba=\dfrac{ab}{a^2}$；

分子 $b\to ab$，分母 $a\to a^2$：都乘了 $a$。

∵$a\ne0$$\dfrac ba$ 有意义，分母 $a\ne0$
∴$\dfrac ba=\dfrac{b\cdot a}{a\cdot a}=\dfrac{ab}{a^2}$分式的基本性质（同乘 $a$）

(2) $\dfrac{a^3}{ab}=\dfrac{a^2}{b}$．

分子 $a^3\to a^2$，分母 $ab\to b$：都除以了 $a$。

∵$a\ne0$$\dfrac{a^3}{ab}$ 有意义，分母 $ab\ne0$
∴$\dfrac{a^3}{ab}=\dfrac{a^3\div a}{ab\div a}=\dfrac{a^2}{b}$分式的基本性质（同除以 $a$）

性质要求 $C\ne0$，所以用 $a$ 去乘、除之前，先说明 $a\ne0$——这正是课本解答的第一句。

课本 p101 例 1。重点讲“∵ a ≠ 0”从哪里来：两个题的左边都是有意义的分式，分母不为 0，所以 a ≠ 0。书写格式照课本：先写条件，再写变形。

例 2 · 例 3

分子、分母和分式本身的符号

例 2 不改变分式的值，使分子与分母都不含“−”号：(1) $\dfrac{-2a}{-3b}$；(2) $\dfrac{-n}{m}$．

(1)$\dfrac{-2a}{-3b}=\dfrac{2a}{3b}$两数相除，同号得正
(2)$\dfrac{-n}{m}=-\dfrac nm$异号得负，“−”号提到分式前面

例 3 使分子与分母的最高次项的系数是正数：

(1)$\dfrac{x}{1-x^2}=\dfrac{x}{-(x^2-1)}=-\dfrac{x}{x^2-1}$分母提出“−”号
(2)$\dfrac{y-y^2}{y+y^2}=\dfrac{-(y^2-y)}{y^2+y}=-\dfrac{y^2-y}{y^2+y}$分子提出“−”号

动手：分式前、分子、分母各有一个符号。点按钮改符号，看值变不变（$a=2$，$b=5$）。

分式本身、分子、分母三处的符号，同时改变其中两处，分式的值不变；只改一处，值变成相反数。

课本 p101–102 例 2、例 3。课本小人提示：把分式看成分子与分母相除，根据“两数相除，同号得正，异号得负”变形。右边的符号开关是补充探究：请学生先预测“改哪两处值不变”，再点按钮验证（值用精确分数计算）。例 3 中“最高次项”是 x² 项，提出“−”号后要变号的是整个多项式的每一项。

分式的约分（课本 p102）

根据分式的基本性质，把一个分式的分子和分母分别除以它们的公因式，叫做分式的约分．

例 4 约分：

(1)$\dfrac{36ab^3c}{6abc^2}=\dfrac{6abc\cdot6b^2}{6abc\cdot c}$找出公因式 $6abc$
$=\dfrac{6b^2}{c}$分子、分母同除以 $6abc$
(2)$\dfrac{(a+b)^3}{(a+b)(a-b)}=\dfrac{(a+b)(a+b)^2}{(a+b)(a-b)}$公因式 $a+b$
$=\dfrac{(a+b)^2}{a-b}$同除以 $a+b$

系数取最大公因数，相同字母取最低次幂：$36ab^3c$ 与 $6abc^2$ 的公因式是 $6abc$。

课本 p102 尝试、约分定义、例 4。约分和分数约分一模一样，只是公因式里有字母。“系数取最大公因数、字母取最低次幂”是找公因式的方法（七年级下 9.5 学过），请学生对照例 4(1) 说出 6、a、b、c 各是怎样来的。

动手约分

先分解，再成对划去公因式

玩法：先点分子里的一个因式，再点分母里相同的因式，两个一起划去（同除以这个因式）。

为什么只能划去因式，不能划去“项”？性质说的是分子、分母都除以同一个整式；$\dfrac{a+b}{a}$ 里的 $a$ 只是分子的一项，分子并不能被 $a$ 整除——不能划。

什么时候算约完了？分子、分母再也找不出相同的因式（只剩公因式 1）。

本课核心。每个分式都已分解成因式“卡片”（例 5(2) 的分母 1 − a² 先提出 −1）。请学生点卡片配对约分；点错（两个因式不同）会提示。约完后系统用代值检验结果与原式是否相等。建议顺序：例 4(1) → 例 4(2) → 例 5 两题 → 练习。

例 5

分子、分母是多项式：先分解因式

约分：(1) $\dfrac{ma+mb-mc}{a+b-c}$；(2) $\dfrac{a^2-2a+1}{1-a^2}$．

分析：当分式的分子、分母为多项式时，先将分式的分子、分母分解因式，然后找出它们的公因式，再约分．

(1)$\dfrac{ma+mb-mc}{a+b-c}=\dfrac{m(a+b-c)}{a+b-c}=m$提公因式，再约去 $a+b-c$
(2)$\dfrac{a^2-2a+1}{1-a^2}=-\dfrac{a^2-2a+1}{a^2-1}$分母提出“−”号
$=-\dfrac{(a-1)^2}{(a-1)(a+1)}$完全平方公式、平方差公式
$=-\dfrac{a-1}{a+1}$约去 $a-1$

最简分式（课本 p103）

如果一个分式的分子与分母只有公因式 1，那么这样的分式叫做最简分式．约分通常要把分式化成最简分式或整式．

例 5(1) 的结果 $m$ 是什么？整式——约分的结果可以是整式。

$\dfrac{a+2}{2}=a$？$\dfrac{x+3}{x+6}=\dfrac12$？取 $a=4$：$\dfrac{4+2}{2}=3\ne4$；取 $x=1$：$\dfrac{4}{7}\ne\dfrac12$。分子、分母都是“和”，没有公因式，不能约。

课本 p103 例 5、分析、最简分式的定义。例 5(2) 有两种写法：也可以先分解再处理符号（1 − a² = −(a − 1)(a + 1)）。典型错误卡请学生先判断，再用代值反驳——“举一个反例”就能说明变形错了。

分式的通分（课本 p103）

根据分式的基本性质，把几个异分母的分式变形成同分母的分式，叫做分式的通分，变形后的分母叫做这几个分式的公分母．

系数$x$$y$
$2x^2y$2$x^2$$y$
$6xy^2$6$x$$y^2$

最简公分母（课本 p104）

如果几个分式的分母都是单项式，那么各分母系数（都是整数）的最小公倍数与所有字母的最高次幂的积叫做这几个分式的最简公分母．

约分找公因式：系数最大公因数、字母最低次幂；通分找最简公分母：系数最小公倍数、字母最高次幂。

课本 p103–104 尝试、通分定义、交流与最简公分母。“通分的关键是确定几个分式的公分母，通常取最简公分母”。用表格一栏一栏取，学生不容易漏字母。最后一张方法卡把约分、通分对照起来，学生最容易把“最低”“最高”弄反。

小结

知识 · 方法 · 思想

知识

$\dfrac AB=\dfrac{A\times C}{B\times C}=\ldots$，$C$ 是不等于 0 的整式。

约分 → 最简分式；通分 → 最简公分母。

方法

分解因式 → 找公因式（系数最大公因数、字母最低次幂）→ 同除。

分解因式 → 最简公分母（系数最小公倍数、字母最高次幂）→ 缺什么乘什么。

思想

分数的基本性质、约分、通分 → 分式的基本性质、约分、通分。

代入几个数精确计算，能发现错误的变形（举反例）。
