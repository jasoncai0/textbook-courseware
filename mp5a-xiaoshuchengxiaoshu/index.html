小数乘小数

小明的房间长 3.8 米、宽 3.2 米，外面的阳台长 3.2 米、宽 1.15 米。

房间的面积是多少平方米？两个因数都是小数，积的小数点怎么点？

先估一估面积图数格子竖式算一算找到规律

课本 p64 例 7。列式：长方形面积 = 长 × 宽，3.8 × 3.2。上一节课学的是小数乘整数，这节课两个因数都是小数。

前情回顾

这些旧知识，今天要用

$2.35\times3$：先看作 $235\times3=705$，因数有 2 位小数，积就有 2 位小数：7.05。

小数乘小数，也先“看作整数”来算。

一个因数乘 10，另一个因数不变，积也乘 10：$4\times3=12$，$40\times3=120$。

两个因数都乘 10，积就乘 100，所以最后要除以 100。

除以 10、100、1000……小数点向左移动一位、两位、三位……

$1216\div100$：小数点向左移动两位，得 12.16。

长方形的面积 = 长 × 宽；边长 1 米的正方形面积是 1 平方米。

用面积图看清 3.8 × 3.2 到底是多少个小方格。

第 2 张卡是四年级下册“积的变化规律”，请学生举例说一说。本课课本竖式右边的“×10、×10、÷100”就是用这条规律。

例 7 · 数一数

面积图：3.8 × 3.2 里有多少个小方格？

长 3.8 米
宽 3.2 米

每个小方格边长 0.1 米，面积是 平方米。3.8 × 3.2 = 38 × 32 个小方格 = 个 0.01 = 12.16 平方米。

本课核心操作。把 1 米平均分成 10 份，每个小方格是 0.1 米 × 0.1 米 = 0.01 平方米（100 个小方格拼成 1 平方米）。长有 38 个 0.1 米，宽有 32 个 0.1 米，小方格一共 38 × 32 = 1216 个——这就是竖式里“看作整数”算的 1216，每个是 0.01，所以是 12.16。“分块看”：9 个整平方米 + 0.1 平方米的长条 + 0.01 平方米的小方格，和竖式的部分积对应。可以拖动滑块换别的长、宽。

先把乘数看成整数，按整数乘法算，再确定积的小数点位置。

乘数中一共有几位小数，就从积的右边起数出几位，点上小数点。

小数乘法这样计算

先按整数乘法算出积，再看因数中一共有几位小数，就从积的右边起数出几位，点上小数点；积的小数末尾有 0，要先点小数点、再去掉。

课本 p65 中间的问题和三个小精灵的话。注意“积（去 0 以前）”：3.680 有 3 位小数，去掉末尾的 0 以后才变成 3.68。第三行是上一课的例子，说明小数乘整数也符合这条规律（整数可以看作 0 位小数）。

辨一辨

先估一估，再判断对不对

$4.6\times2.8=128.8$

只数了一个因数的小数位数。估一估：5 × 3 = 15，积不可能是 128.8。一共 2 位小数：12.88。

$0.64\times7.5=0.48$

先去 0 再点小数点，错了。4800 要先数出 3 位：4.800，再去 0 得 4.8。估一估：0.64 × 7.5 比 0.5 × 7 = 3.5 大。

$3.2\times1.15=3.68$

对。3680 数出 3 位是 3.680，去掉末尾的 0 是 3.68。估一估：3 × 1 = 3，差不多。

① 数一数：两个因数一共几位小数，积就有几位（先点小数点再去 0）；② 估一估：把因数看成接近的整数，看积的大小合不合理。

三道题都是本课出现过的算式，错法是学生最常见的两种：只数一个因数的位数；先去掉末尾的 0 再数位数。用估算检查是很实用的习惯。
