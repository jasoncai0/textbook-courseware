# 课本插件 · 统编版语文 HTML 互动课件

这是小学一年级至初中九年级统编版语文课件，每课一个网页，打开即用，不需要安装，也不需要构建。

- 在线访问：https://jasoncai0.github.io/textbook-courseware/

## 设计原则

- **为教学服务，不为炫技**：跟着课文的节奏走，补全课文里的想象，给学生留下记忆点。
- **按文体选呈现方式**：

  | 文体 | 呈现方式 |
  |---|---|
  | 记叙文 | 画面 + 字幕 |
  | 说明文 | 信息图 |
  | 古诗 | 竖排诗 + 节奏 + 背诵挖空 |
  | 文言文 | 横排对译 |
  | 议论文 | 论证结构图 |
  | 低年级 | 拼音课、识字课模板 |

- **每课第 2 页“读准字音”**：拼音取自课本注音。
- **一课一特色**：每课至少有一个本课独有的互动或呈现方式。
- **教师提示**：按 `N` 打开。

## 使用

| 操作 | 按键 / 手势 |
|---|---|
| 下一步 / 上一步 | `→` 或空格 / `←`，手机左右滑动 |
| 教师提示 | `N` |
| 全屏 | `F` |
| 回到目录 | `H` |

本地使用：克隆仓库后，在根目录起任意静态服务器即可，例如 `python3 -m http.server`。

## 目录结构

- `index.html`、`catalog.js`：目录页和课程数据。
- `shared/`：各课共用的模板。
  - `deck`：翻页引擎
  - `narrative`：记叙文
  - `poem`：诗文
  - `pinyin`：注音
  - `hanzi`：识字
  - `hanyu`：拼音
- `<课目录>/`：一课一个目录，包含 `index.html`、`course.js`、`course.css`、`ziyin.js`、`assets/`（配图）。
- 课目录前缀：

  | 前缀 | 对应册次 |
  |---|---|
  | `x1a` / `x1b` … `x6` | 一年级上下册 … 六年级下册 |
  | 无前缀 | 六年级上册 |
  | `x7a` … `x9b` | 七年级上册 … 九年级下册（陆续上线） |

## 素材说明

- **配图**：由 AI 生成（LibTV：Seedream 生图，Hailuo 图生视频），只作想象参考。
  - 涉及真实人物时只画背影或远景。
  - 战争、苦难题材只用空镜，保持克制。
- **图片**：压缩后的 JPG，放在仓库里。
- **视频**：不放进仓库，页面直接引用 LibTV CDN 地址；少数视频的路径在脚本里拼接，这部分保留本地 mp4。
