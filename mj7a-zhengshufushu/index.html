七年级上册 · 第2章 有理数 · 2.1

正数与负数

珠穆朗玛峰的高程纪念碑上刻着 8 844.43；新疆吐鲁番艾丁湖边的石碑上刻着“海拔 −154 米”。

同样是“海拔”，为什么一个数前面多了一个“−”号？它表示什么意思？

正数 · 负数 · 0温度计与海平面相反意义的量整数与分数

课本 p12 情境（高程测量纪念碑、旅游纪念碑）。第 2 章的第一课。负数在五年级上册已经初步认识过，本课的任务是：把小学的认识整理成规范的数学语言（正数、负数、0 的地位、读法），并为下一课“有理数”做好分类准备。

知识链接

小学里，我们已经见过负数

温度计上，0 ℃ 以下的温度用负数表示：零下 5 ℃ 记作 −5 ℃。

第 5 页：在温度计上读数、记数。

收入 100 元记作 +100 元，支出 60 元记作 −60 元。

第 6、8 页：用正数、负数表示相反意义的量。

0，1，2，3，…是整数；$\frac13$、$\frac{9}{10}$ 是分数；0.32 是小数，$0.32=\frac{32}{100}$。

第 9 页：把数分成整数和分数两类。

本课主线：“−”号不只是“减”——放在数的前面，它表示与“正”意义相反的量。

五年级上册第一单元“负数的初步认识”学过温度、收支、海拔等例子，请学生回忆一两个。第三张卡为第 9 页的分类做准备：有限小数可以写成分数。

概念

正数、负数，以及特殊的 0

正数与负数（课本 p12）

像 8 844.43、100、357、78 这样的数是正数（positive number）；像 −154、−38.87、−117.3、−0.102% 这样的数是负数（negative number）．
0 既不是正数，也不是负数．

“+”读作“正”：$+\dfrac23$ 读作“正三分之二”，正号通常省略不写。一样。$5$ 就是 $+5$。

“−”读作“负”：−117.3 读作“负一百一十七点三”。负百分之零点一零二。

0 的身份：都不是。0 是正数和负数的分界，0 ℃、海平面（海拔 0 m）都是“基准”。

“0 ℃”不是“没有温度”，“海拔 0 m”不是“没有高度”。这里的 0 表示一个标准，正、负都是和它比。

在计算器上输入负数，要用负号键 (−)：输入 −5，依次按 (−) 5。

课本 p12 正数、负数的描述与读法。“正数”“负数”是描述性的：大于 0 的数叫正数、小于 0 的数叫负数，要到 2.3 节学了数轴比较大小才说清。这里强调两件事：正号可省略；0 既不是正数也不是负数。“−”这个符号以前只表示减法，第一次表示“负”，要读给学生听。

动手观察

拖一拖：0 以上记正，0 以下记负

把温度从 3 ℃ 拖到 −3 ℃：这两个温度有什么不同？一个在 0 ℃ 以上 3 ℃，一个在 0 ℃ 以下 3 ℃——离 0 一样远，意义相反。

课本习题 2.1 第 4 题：直升机“停”在离海面 80 m 的低空，潜水艇潜在水下 50 m。设海平面的高度为 0 m：直升机 $+80$ m，潜水艇 $-50$ m。

先定一个“0”（基准），比它高、比它多的记作正，比它低、比它少的记作负。

本课核心交互。温度计：拖动红色液柱顶端（每小格 1 ℃），右边实时显示“记作”与“读作”。海平面：拖动物体，在海面以上显示直升机、以下显示潜水艇，并给出海拔。请学生把直升机拖到 80 m、潜水艇拖到 −50 m（习题 2.1 第 4 题、章首页图），再对比两个“0”：0 ℃ 和海平面。

概念

具有相反意义的量

课本 p13

0 ℃ 以上的温度用正数表示，0 ℃ 以下的温度用负数表示．日常生活中，许多具有相反意义的量都可以用正数、负数来表示．
用正数表示用负数表示“0”是什么？
高于海平面的高度低于海平面的高度海平面
收入若干元支出若干元不收不支
向北走向南走出发点
盈利亏损不盈不亏
水位上升水位下降原来的水位

把哪一种记作正，是人为规定的；规定好以后，相反的那一种就记作负。“相反意义”要在同一类量里找：向北和向东不是相反意义。

课本 p13 的三组例子（温度、海拔、收支）后面跟着“……”，第 4～6 行请学生补充，后两行来自习题 2.1 第 3 题。强调“规定”二字：例 2 里“向北为正”就是一种规定。

例 1

指出下列各数中的正数、负数

课本 p13 例 1：先点一个数，再点它该去的地方．

解：$+7$、$\dfrac13$、$998$ 是正数，$-9$、$-4.5$、$-\dfrac{9}{10}$ 是负数．

$\dfrac13$ 前面没有“+”，为什么是正数？0 为什么哪一边都不放？正号省略不写，$\dfrac13=+\dfrac13$；0 既不是正数也不是负数。

课本 p13 例 1。请学生上台点选，错了会提示原因。课本的解答没有提到 0，这里特意加了一个“既不是正数也不是负数”的框，让 0 有地方可去。

例 2

规定了“正”，“负”就跟着确定

(1)向北走 8 km 记作 $+8$ km规定向北为正
　向南走 5 km 记作 $-5$ km向南与向北意义相反
(2)运进粮食 3 t 记作 $+3$ t规定运进为正
　$-4$ t 表示运出粮食 4 t运出与运进意义相反

先找规定（谁是正）→ 再找它的反面 → 负数后面的数字就是“反面”的多少。

课本 p13 例 2。(1) 的图按比例画：向北 8 格，向南 5 格。答 (2) 时容易说成“运进 −4 t”，要说成“运出 4 t”：负号已经表示“反方向”，后面就不再带负号。

分类

数的家庭：整数和分数

整数
正整数1，2，3，…零0负整数−1，−2，−3，…
分数
正分数$\frac13$，$\frac{12}{5}$，0.32，…负分数$-\frac{9}{10}$，−4.5，…

正整数、负整数、零统称为整数（integer）．

正分数、负分数统称为分数（fraction）．

−4.5 和 0.32 是小数，为什么放进“分数”？$-4.5=-\dfrac92$，$0.32=\dfrac{32}{100}=\dfrac{8}{25}$：有限小数都能写成分数。

0 是整数吗？是正整数吗？0 是整数，但不是正整数，也不是负整数。

整数和分数合在一起，就是 2.2 要学的有理数。

课本 p13 整数、分数的说法。小学里“自然数”“整数”只有 0 和正的，现在整数里多了负整数、分数里多了负分数。把有限小数看作分数是为下一课“有理数 = 能写成分数的数”做准备，课本 2.2 开头会说明。

小结

知识 · 方法 · 下一步

知识

正数、负数；0 既不是正数，也不是负数；“+”读正（可省略）、“−”读负。

整数：正整数、0、负整数；分数：正分数、负分数。

方法

先定基准“0”和“正”的意义 → 相反的记作负。

模型

温度计、海平面：0 以上为正、0 以下为负——把它横过来，就是 2.3 节的数轴。
