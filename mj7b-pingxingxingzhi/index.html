七年级下册 · 第7章 平面图形的认识（二） · 7.2

探索平行线的性质

上节课：同位角相等、内错角相等、同旁内角互补，都能推出两直线平行。

反过来，如果两条直线已经平行（像笔直的两条铁轨），被第三条直线所截，同位角、内错角、同旁内角会有怎样的数量关系？

剪纸片叠合八个角只有两种大小判定 ↔ 性质反证说理

课本 p13 开篇语。先请学生把上节课的三个判定背一遍，再提出“反过来”的问题，让学生先猜：平行时同位角会怎样？

前情回顾

今天要用到的旧知识

同位角相等，两直线平行；

内错角相等，两直线平行；

同旁内角互补，两直线平行。

本课研究它们“反过来”的说法；例题里两类结论要配合使用。

对顶角相等；邻补角的和是 $180^\circ$。

等量代换：$\angle1=\angle2$，$\angle1=\angle3$，则 $\angle2=\angle3$。

由“同位角相等”说理得到“内错角相等”“同旁内角互补”。

过直线外一点，有且只有一条直线与这条直线平行。

读一读：用它说明“两直线平行，同位角相等”。

本课主线：已知两直线平行 ⇒ 同位角、内错角、同旁内角各有什么关系？

第一张卡请学生口头说出三个判定，并说出“条件”和“结论”分别是什么——判定的条件是角的关系，结论是平行。本课的性质恰好把条件和结论交换。

数学实验室

剪下纸片，把一对角叠在一起

移动纸片

在练习本上画 $AB\parallel CD$，再画直线 $EF$ 与它们相交（图 7-10）。剪下含 $\angle1$ 的纸片（图 7-11），去盖 $\angle2$。

同位角沿 $EF$ 平移，$\angle1$ 正好盖住 $\angle2$：每对同位角都相等
内错角绕两交点连线的中点转半圈，$\angle7$ 正好盖住 $\angle2$：每对内错角都相等
同旁内角$\angle5$ 平移下来与 $\angle2$ 拼成一个平角：每对同旁内角都互补

$AB$ 与 $CD$ 不平行时，纸片怎么也盖不严——“两直线平行”这个条件不能少。

课本 p13 数学实验室 1、2（图 7-10、7-11）与 p14 做一做（图 7-12）。拖滑块让纸片一点点移动，请学生预测“能不能盖严”。三种动法正好对应三类角：同位角——平移（7.3 会专门学），内错角——转半圈，同旁内角——拼成平角。最后勾上“歪 6°”做对照实验。

性质

两直线平行，同位角相等

课本 p14

两条平行直线被第三条直线所截，同位角相等．
简单说成：两直线平行，同位角相等．

我们通过实验发现了这个结论，以后可以加以证实（第 11 页“读一读”）。

已知（条件）得到（结论）
判定（7.1）同位角相等⇒两直线平行
性质（7.2）两直线平行⇒同位角相等

判定：由“角的关系”得到“线的位置关系”；
性质：由“线的位置关系”得到“角的关系”。

“同位角相等”单独说是错的：第 3 页 $AB$ 歪了 $6^\circ$，同位角就差了 $6^\circ$。

想一想：已知 $a\parallel b$，内错角、同旁内角又有什么关系？能不能不剪纸，用说理得到？内错角相等，同旁内角互补——下面来说理。

课本 p14 结论框。用表格把判定和性质“上下对齐”，让学生看出条件与结论正好交换。这一页不急着做题，重点是分清两者的方向，后面辨析页还会专门练。

说理

由“同位角相等”推出另外两个性质

图 7-13：$a\parallel b$，求证 $\angle2=\angle3$．

∵$a\parallel b$，已知
∴$\angle1=\angle2$．两直线平行，同位角相等
又$\angle1=\angle3$，对顶角相等
∴$\angle2=\angle3$．等量代换

图 7-14：$a\parallel b$，求证 $\angle2+\angle3=180^\circ$．

∵$a\parallel b$，∴ $\angle1=\angle2$．两直线平行，同位角相等
又$\angle1+\angle3=180^\circ$，$\angle1$、$\angle3$ 是邻补角
∴$\angle2+\angle3=180^\circ$．等量代换

课本 p15

两条平行直线被第三条直线所截，内错角相等．简单说成：两直线平行，内错角相等．
两条平行直线被第三条直线所截，同旁内角互补．简单说成：两直线平行，同旁内角互补．

课本 p14 下半页“证实小丽、小明得到的结论”。和 7.1 第 8 页的说理对照：那时是用对顶角、邻补角“走向”同位角，现在是从同位角“走出来”。每个“理由”先让学生说。

观察

两直线平行时，八个角只有两种大小

拖动截线 $EF$ 上的橙色点改变它的方向

$\angle1=\angle7=\angle2=\angle8$ $\angle3=\angle5=\angle4=\angle6$

为什么两种大小加起来总是 $180^\circ$？同一顶点处相邻的两个角是邻补角。

两直线平行时，知道八个角中的任意一个，就能求出其余七个：相等的两组颜色相同，不同颜色的两角互补。

试一试：截线与 $AB$ 垂直时会怎样？八个角都是 $90^\circ$：截线也与 $CD$ 垂直（练一练 1）。

本页把三个性质“合在一起看”：拖动截线，蓝色四个角始终相等、橙色四个角始终相等，两色相加 180°。最后一问把截线拖成竖直，为练一练第 1 题（l₃ ⊥ l₁ ⇒ l₃ ⊥ l₂）做铺垫。

辨一辨

这一步用的是判定，还是性质？

① 因为 $\angle1=\angle2$，所以 $a\parallel b$．（$\angle1$、$\angle2$ 是同位角）

由角的关系得到平行：理由写“同位角相等，两直线平行”。

② 因为 $a\parallel b$，所以 $\angle1=\angle2$．（$\angle1$、$\angle2$ 是同位角）

由平行得到角的关系：理由写“两直线平行，同位角相等”。

③ 因为 $a\parallel b$，所以 $\angle2+\angle5=180^\circ$．（同旁内角）

已知平行，求角：性质“两直线平行，同旁内角互补”。

④ 因为 $\angle2=\angle7$，所以 $a\parallel b$．（内错角）

由角得线：判定“内错角相等，两直线平行”。

看“因为”后面：是角的关系 → 用判定（得平行）；是平行 → 用性质（得角）。

点选判断，点对了显示理由。学生最常见的错误是理由写反：明明已知平行，却写“同位角相等，两直线平行”。可让学生把四句话的理由完整说出来。

例题

性质与判定接力使用

例　如图 7-15，$AB\parallel CD$，$\angle A=\angle D$．判断 $AF$ 与 $ED$ 是否平行，并说明理由．

思路：要证 $AF\parallel ED$，需要一对“相等的同位角或内错角”。$\angle A$、$\angle D$ 不是这样的一对，找一个“中间角”——$\angle BED$：它和 $\angle D$ 是内错角，和 $\angle A$ 是同位角。

解$AF\parallel ED$．
∵$AB\parallel CD$，已知
∴$\angle D=\angle BED$．两直线平行，内错角相等（性质）
又$\angle A=\angle D$，∴ $\angle A=\angle BED$．等量代换
∴$AF\parallel ED$．同位角相等，两直线平行（判定）

由已知的平行用性质得角相等 → 角之间代换 → 用判定得新的平行。

课本 p15 例。关键是引入“中间角”∠BED。请学生在图上找：∠BED 与 ∠D 构成“Z”形，与 ∠A 构成“F”形。最后让学生说出每一步用的是性质还是判定。

练一练

用性质求角、判断位置关系

1. 如图，$l_1\parallel l_2$，$l_3\perp l_1$．$l_3$ 与 $l_2$ 有怎样的位置关系？为什么？

提示 1$l_3\perp l_1$，所以 $l_3$ 与 $l_1$ 所成的角是 $90^\circ$；它与 $l_3$、$l_2$ 所成的角是同位角。
完整解答$l_3\perp l_2$．∵ $l_1\parallel l_2$，∴ $l_3$ 与 $l_2$ 所成的角等于 $l_3$ 与 $l_1$ 所成的同位角，等于 $90^\circ$（两直线平行，同位角相等），∴ $l_3\perp l_2$．

2. 如图，$CD\parallel EF$，$DE\parallel AC$．图中哪些角相等？为什么？

提示 1分两组看：被 $CD$、$EF$ 截出的角；被 $DE$、$AC$ 截出的角。
完整解答由 $CD\parallel EF$：$\angle BFE=\angle BDC$，$\angle BEF=\angle BCD$（同位角），$\angle FED=\angle EDC$（内错角）；
由 $DE\parallel AC$：$\angle BDE=\angle A$，$\angle BED=\angle BCA$（同位角），$\angle EDC=\angle DCA$（内错角）．
理由都是两直线平行的性质．

3. 如图，点 $B$、$C$、$D$ 在一条直线上，$AB\parallel EC$，$\angle A=55^\circ$，$\angle B=60^\circ$．求 $\angle1$、$\angle2$ 和 $\angle ACB$ 的度数．

提示 1$\angle1$ 与 $\angle A$ 是内错角，$\angle2$ 与 $\angle B$ 是同位角。
完整解答∵ $AB\parallel EC$，∴ $\angle1=\angle A=55^\circ$（两直线平行，内错角相等），$\angle2=\angle B=60^\circ$（两直线平行，同位角相等）．
∵ $B$、$C$、$D$ 在一条直线上，∴ $\angle ACB=180^\circ-\angle1-\angle2=65^\circ$．

课本 p15 练一练 1–3。第 3 题算出 ∠A + ∠B + ∠ACB = 55° + 60° + 65° = 180°——这正是 7.5 “三角形内角和是 180°”的说理方法，可以先让学生留意这个巧合。

读一读

怎样证实“两直线平行，同位角相等”

假设 $\angle1$ 比 $\angle2$ 大

如图，$AB\parallel CD$，$\angle1$ 与 $\angle2$ 是同位角．

假设$\angle1\ne\angle2$，过点 $O$ 作直线 $GH$，使 $\angle EOH=\angle2$．$GH$ 与 $AB$ 是两条直线
则$GH\parallel CD$．同位角相等，两直线平行（基本事实）
于是过点 $O$ 有两条直线 $AB$、$GH$ 都与 $CD$ 平行．与“过直线外一点有且只有一条直线与这条直线平行”矛盾
所以$\angle1\ne\angle2$ 的假设不正确，$\angle1=\angle2$．

课本 p16 读一读。这是学生第一次接触“先假设结论不成立，推出矛盾”的说理方式（以后叫反证法），不要求掌握。左图：拖滑块设定“假设 ∠1 比 ∠2 大多少度”，图中画出满足 ∠EOH = ∠2 的直线 GH——它和 AB 是两条不同的直线，却都“应该”平行于 CD；拖到 0° 时 GH 与 AB 重合，矛盾消失。

习题 7.2

自己试试：卡住了再点提示

3. 要在长方形钢板 $ABCD$ 的边 $AB$ 上找一点 $E$，使 $\angle AEC=150^\circ$，应怎样确定点 $E$ 的位置？为什么？

提示 1$\angle AEC=150^\circ$，则 $\angle CEB=30^\circ$；$DC\parallel AB$。
完整解答在 $C$ 处作 $\angle DCE=30^\circ$，射线 $CE$ 与 $AB$ 的交点就是 $E$．∵ $DC\parallel AB$，∴ $\angle CEB=\angle DCE=30^\circ$（两直线平行，内错角相等），∴ $\angle AEC=180^\circ-30^\circ=150^\circ$．

4. 如图，$AD\parallel EF$，$\angle1+\angle2=180^\circ$．$\angle1$ 与 $\angle BAD$ 相等吗？为什么？

提示 1$AD\parallel EF$，$\angle2$ 与 $\angle BAD$ 是同旁内角。
完整解答相等．∵ $AD\parallel EF$，∴ $\angle2+\angle BAD=180^\circ$（两直线平行，同旁内角互补）．又 $\angle1+\angle2=180^\circ$，∴ $\angle1=\angle BAD$（同角的补角相等）．

5. 点 $E$、$A$、$C$ 在一条直线上，$AD\perp BC$，$EG\perp BC$，垂足分别为 $D$、$G$，$EG$ 交 $AB$ 于点 $F$，且 $\angle1=\angle2$．$\angle BAD$ 与 $\angle CAD$ 相等吗？为什么？

提示 1先由两个“垂直”得到 $AD\parallel EG$（同位角都是 $90^\circ$）。
提示 2$\angle1$ 与 $\angle CAD$ 是同位角，$\angle2$ 与 $\angle BAD$ 是内错角。
完整解答相等．∵ $AD\perp BC$，$EG\perp BC$，∴ $AD\parallel EG$（同位角相等，两直线平行）．∴ $\angle1=\angle CAD$，$\angle2=\angle BAD$（两直线平行，同位角相等、内错角相等）．又 $\angle1=\angle2$，∴ $\angle BAD=\angle CAD$．

课本 p17 习题 7.2 第 3–5 题。第 5 题先判定、再用性质，是本课“判定与性质接力”的综合题。第 1、2 题可口答：第 1 题由 a ∥ b 写出 4 对同位角相等、2 对内错角相等、2 对同旁内角互补。

小结

知识 · 方法 · 思想

知识

两直线平行 ⇒ 同位角相等、内错角相等、同旁内角互补。

判定：角 ⇒ 平行；性质：平行 ⇒ 角。

方法

剪纸叠合发现结论，再用基本事实、对顶角、邻补角说理。

性质得角相等 → 等量代换 → 判定得新的平行。

思想

知道一个角，平行线就把它“搬”到别处；八个角只有两种大小。

假设结论不成立，推出与基本事实矛盾。
