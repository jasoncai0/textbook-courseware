3 的倍数的特征

2 和 5 的倍数，看个位就知道。3 的倍数呢？

13、23、33，个位都是 3，可只有 33 是 3 的倍数……秘密藏在哪儿？

百数表计数器拨珠各位上数的和

开门见山制造冲突：个位相同的 13、23、33，结果不同，说明 3 的倍数不能只看个位。让学生先猜一猜秘密在哪里。

3 的倍数：3，6，9，12，15，18，21，24，27，30，……

判断珠子总数是不是 3 的倍数。

今天的问题：3 的倍数有什么特征？

第 2 张卡：计数器上每一位拨的珠子个数，就是这一位上的数。本课的核心活动就是“数珠子”。

概括

3 的倍数的特征

课本这样说

3 的倍数，它各位上数的和一定是 3 的倍数。

反过来：如果一个数不是 3 的倍数，它各位上数的和会是 3 的倍数吗？找几个这样的数算一算。

52：$5+2=$

52 ÷ 3 = 17……1

104：$1+0+4=$

104 ÷ 3 = 34……2

98：$9+8=$

98 ÷ 3 = 32……2

各位上数的和都 不是 3 的倍数。

看一个数是不是 3 的倍数：把各位上的数加起来，和是 3 的倍数，这个数就是 3 的倍数；和不是，这个数就不是。

为什么？一个十 = 9 + 1，一个百 = 99 + 1。9、99 都是 3 的倍数，拿走它们，每颗珠只剩下“1”——剩下的就是珠子总数。

课本 p34 中间。课本的问题“如果一个数不是 3 的倍数，这个数各位上数的和会是 3 的倍数吗”，让学生自己举例算。最后一行“为什么”供学有余力的学生思考，不要求全班掌握：42 = 4 个十 + 2 = 4 × 9 + 4 + 2，4 × 9 一定是 3 的倍数，所以只看 4 + 2。

练习五 · 第 8 题

在 □ 里填一个数字，使组成的数是 3 的倍数

点 □ 下面的数字试一试。你能找到多少种不同的填法？

先把已知的数字加起来，再看还差几就是 3 的倍数：比如 7□，7 + 2 = 9，所以填 2；再添 3、再添 3，还可以填 5、8。

课本 p36 练习五第 8 题。每填一个，下面显示各位上数的和；找全了会显示“全部找到”。共有：7□ 填 2、5、8；□12 填 3、6、9（首位不能是 0）；20□ 填 1、4、7；3□5 填 1、4、7。规律：找到一个后，每次加 3 就是下一个。

综合

2、3、5 的倍数特征一起用

1.（练习五第 12 题）下面的数，哪些是 3 的倍数？

27　30　48　65　102　147　345

3 的倍数：

提示 165：6 + 5 = 11，不是 3 的倍数。其余的都算一算。
完整解答27、30、48、102、147、345 是 3 的倍数；再看个位，30 和 345 也是 5 的倍数，30、48、102 也是 2 的倍数。

2.（练习五第 13 题）在 □ 里填数字。

既是 2 的倍数又是 3 的倍数：24，37
既是 5 的倍数又是 3 的倍数：10

提示 1先用 2 或 5 的特征定下个位能填哪几个，再用 3 的特征挑。
提示 224□：个位要是 0、2、4、6、8；2 + 4 + □ 要是 3 的倍数。
完整解答24□ 填 0 或 6；37□ 填 2 或 8；10□ 只能填 5（100 的 1 + 0 + 0 = 1 不行）。
6 的因数有 1，2，3，6，除了 6 本身，$1+2+3=6$。像 6 这样的数叫作完全数（也叫完美数）。28 也是完全数：$1+2+4+7+14=28$。

课本 p36 练习五第 12、13 题，以及 p34“你知道吗”的完全数。第 2 题方法：两个条件，先用简单的（看个位）缩小范围，再用 3 的特征检验。

辨一辨

对还是不对？

1. 个位上是 3、6、9 的数都是 3 的倍数。

13 的个位是 3，但 1 + 3 = 4，不是 3 的倍数。3 的倍数不能看个位。

2. 一个数各位上数的和是 12，这个数是 3 的倍数。

12 是 3 的倍数，所以这个数是 3 的倍数（比如 75、444）。

3. 把 312 的数字换个顺序，变成 132、231、213……它们都是 3 的倍数。

换顺序，各位上数的和不变：都是 3 + 1 + 2 = 6。

2、5 的倍数：看个位；3 的倍数：看各位上数的和。

第 3 题可以引出练习五第 9 题：从 0、5、6、7 中选 3 个数字组成 3 的倍数的三位数，只要选的三个数字之和是 3 的倍数（0、5、7 或 5、6、7），顺序可以任意排（0 不能放百位）。
