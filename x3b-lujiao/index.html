三年级下册 · 第二单元 · 第 7 课 · 寓言

鹿角和鹿腿

根据《伊索寓言》相关内容改写

读寓言故事，明白其中的道理

读故事　→　读出心情变化　→　称一称角和腿　→　明道理

鹿的心情一变再变：欣赏角—抱怨腿—逃命—感叹。读的时候跟着鹿的心情走。

读故事池塘照影

丛林中，住着一只漂亮的鹿。

有一天，鹿口渴了，找到一个池塘，痛痛快快地喝起水来。池水清清的，像一面镜子。鹿忽然发现了自己倒映在水中的影子：

鹿“咦，这是我吗？”

鹿摆摆身子，水中的倒影也跟着摆动起来。他从来没有注意到自己是这么漂亮！他不着急离开了，对着池水欣赏自己的美丽：

鹿 · 欣赏“啊！我的身段多么匀称，我的角多么精美别致，好像两束美丽的珊瑚！”

“咦”——惊奇；“啊！”——得意。“精美别致”：精致美丽、与众不同。“像两束美丽的珊瑚”：比喻，写出角的美。

读故事嫌弃细腿

一阵清风吹过，池水泛起了层层波纹。鹿忽然看到了自己的腿，不禁噘起了嘴，皱起了眉头：

鹿 · 抱怨“唉，这四条腿太细了，怎么配得上这两只美丽的角呢！”

鹿开始抱怨起自己的腿来。

“不禁噘起了嘴，皱起了眉头”——鹿的心情从得意变成了不满。“唉”字要读出失望。

读故事狮口逃命

就在他没精打采地准备离开的时候，忽然听到远处传来一阵脚步声。他机灵地支起耳朵，不错，正是脚步声！

鹿猛一回头，哎呀，一头狮子正悄悄地向自己逼近。

鹿不敢犹豫，撒开长腿就跑。有力的长腿在灌木丛中蹦来跳去，不一会儿，就把凶猛的狮子远远地甩在了后面。

“哎呀”——惊慌！刚才被嫌弃的“细腿”，现在成了“有力的长腿”。读到这里停一停：腿帮了大忙。

读故事角被挂住了

就在狮子灰心丧气不想再追的时候，鹿的角却被树枝挂住了。

狮子赶紧抓住这个机会，猛扑过来。

眼看就要追上了，鹿用尽全身力气，使劲一扯，才把两只角从树枝中挣脱出来，然后又拼命向前奔去。

这次，狮子再也没有追上。

最紧张的时候：被夸成“珊瑚”的角，偏偏被树枝挂住了！读得急一些、紧张一些。

读故事小溪边

鹿跑到一条小溪边，停下脚步，一边喘气，一边休息。他叹了口气，说：

“两只美丽的角差点儿让我送了命，可四条难看的腿却让我狮口逃生！”

鹿最后明白了什么？这句话把“角”和“腿”放在一起比，是全文的关键句。

读出鹿的心情变化

感叹 · 醒悟

课后第 1 题：朗读课文，注意读出鹿的心情变化。抓住“咦、啊、唉、哎呀”几个叹词，心情变了，语气也要变。

品 · 想一想

鹿心里的天平：角重要，还是腿重要？

池塘边：角“精美别致”，鹿“欣赏”；腿“太细了”，鹿“抱怨”——天平倒向角。

狮子来了：腿让它“狮口逃生”；角却“差点儿让我送了命”——天平翻了过来！

想一想：角真的没用吗？腿只是“难看”吗？看东西，不能只看漂亮不漂亮。

点两个按钮，看天平怎么翻转。提醒学生：天平翻过来以后，也不是说角就“没用”——这为下一页课后第 3 题的讨论做准备。

讲故事 · 课后第 2 题

根据提示，用自己的话讲故事

提示：角：美丽　欣赏 → 差点儿送命；腿：难看　抱怨 → 狮口逃生。讲出鹿的心情变化，故事更生动。

课后第 2 题：根据提示讲故事。先同桌互讲，再请一两位同学上台，可以加上鹿的动作和表情。

品 · 课后第 3 题

下面的说法，你赞成哪一种？

先选一选，再说说你的理由。最后用一句话说说：这个故事告诉我们什么？

联系生活：下面哪些做法懂得这个道理？

小知识：鹿角是雄鹿的武器，可以用来抵抗敌人、和同伴争斗。所以，角也不是“没用”的。

课后第 3 题：开放讨论，两种观点言之有理都可以。引导学生体会：事物各有长处和短处，不要只看外表。为什么这样设计：本课的道理用“天平”称过一次，这里再让学生选立场、说理由，自己把道理说出来，不再另设“故事—道理”翻卡页。

读与写 · 讲故事

讲一讲，写一写

选一个练习，先说给同桌听，再写下来。

讲故事时用上提示词；续编时想一想：鹿再到池塘边照影子，还会抱怨腿吗？

回顾

鹿角和鹿腿

鹿 角 和 鹿 腿
角　美丽　欣赏　→　差点儿送命
腿　难看　抱怨　→　狮口逃生
心情　惊奇 → 得意 → 不满 → 惊慌 → 感叹
不能只看外表　各有各的长处

读寓言：跟着人物的心情读故事，从故事的“转折”里想道理。
