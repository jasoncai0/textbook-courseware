九年级上册 · 第2章 对称图形——圆 · 2.2

圆的对称性

轮子绕固定轴心旋转，不论转到什么位置，都与初始位置重合。

圆是中心对称图形，也是轴对称图形——这两种对称性，能帮我们推出哪些相等的弧、相等的弦？

旋转 · 叠合圆心角、弧、弦的关系折叠垂径定理

课本 p44 情境。本章章名就叫“对称图形——圆”：本节用“图形运动”（旋转、翻折）发现并证实圆的性质，这是本章的研究方法。

前情回顾

今天要用到的旧知识

旋转前后：对应线段相等，对应角相等。把一个图形绕某一点旋转 180°，如果能与自身重合，它就是中心对称图形。

圆绕圆心旋转；把两个圆心角叠合。

如果一个图形沿一条直线折叠，直线两旁的部分能够互相重合，它就是轴对称图形；对称轴垂直平分对应点的连线。

沿直径折叠，证实垂径定理。

等腰三角形底边上的高、底边上的中线、顶角平分线互相重合（三线合一）。

垂径定理的推理证明：$OC=OD$，$OP\perp CD$。

弦、弧、优弧、劣弧、圆心角、等圆、等弧；同圆或等圆的半径相等。

本节研究圆心角、弧、弦之间的关系。

本节主线：旋转 → 圆心角、弧、弦的关系；翻折 → 垂直于弦的直径的性质（垂径定理）。

前两张卡对应本节两条主线。请学生先说一说：中心对称图形和轴对称图形分别是怎样定义的？各举一例。

旋转

圆绕圆心旋转任意角度

旋转角 $\alpha=$

拖动滑块，让 $\odot O$ 绕圆心 $O$ 旋转（蓝色是旋转后的圆，虚线是原来的位置；红点、弦只是做的记号）。

旋转多少度，圆与原来的圆重合？任何角度：圆上每一点到 $O$ 的距离都等于半径，转过去仍在原来的圆上。（记号会移走，但圆本身始终重合。）

圆是中心对称图形，圆心是它的对称中心．（课本 p44）

转 $180^\circ$ 重合，所以是中心对称图形；圆更特殊——转任何角度都重合（旋转不变性）。

课本 p44。旋转由坐标精确计算。追问：正方形转多少度与自身重合？（90° 的整数倍）正三角形呢？（120° 的整数倍）圆却是任意角度——这条性质就是下一页“叠合”方法的依据。

操作与思考

相等的圆心角，所对的弧、弦相等吗？

叠合进度

在两张透明纸片上，分别画半径相等的 $\odot O$ 和 $\odot O'$，再画相等的圆心角 $\angle AOB$ 和 $\angle A'O'B'$，连接 $AB$、$A'B'$（图 2-9）．还有哪些相等的线段、相等的弧？

①使点 $O$ 与点 $O'$ 重合平移纸片
②旋转，使射线 $O'A'$ 与 $OA$ 重合圆绕圆心旋转，仍与自身重合
∵$\angle A'O'B'=\angle AOB$射线 $O'B'$ 与 $OB$ 重合
又∵$O'A'=OA$，$O'B'=OB$点 $A'$ 与 $A$、$B'$ 与 $B$ 重合
∴$\overset{\frown}{AB}=\overset{\frown}{A'B'}$，$AB=A'B'$完全重合

课本 p44–45 操作与思考、图 2-10。两个小人的猜想：AB = A′B′；弧 AB = 弧 A′B′。拖动进度条：0→1 平移使 O′ 与 O 重合，1→2 绕 O 旋转使 O′A′ 与 OA 重合（图中两个圆心角都是 70°，开始时 ⊙O′ 里的角比 ⊙O 里的多转了 40°）。这就是课本说的“运用图形运动的方法证实猜想”。

定理

圆心角、弧、弦：一组相等，其余都相等

拖动点 $D$，改变 $\angle COD$

课本 p45

在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦相等．

思考与探索　如果圆心角所对的弧相等，那么它们所对的弦相等吗？这两个圆心角相等吗？如果弦相等呢？都相等（拖到弦长相等时，三行同时变绿）。

课本 p45

在同圆或等圆中，如果两个圆心角、两条弧、两条弦中有一组量相等，那么它们所对应的其余各组量都分别相等．

把顶点在圆心的周角等分成 360 份，每一份是 $1^\circ$ 的圆心角，所对的弧叫做 $1^\circ$ 的弧．圆心角的度数与它所对的弧的度数相等．

“同圆或等圆”：两个同心圆中，相等的圆心角所对的弧度数相等，弧却不相等（不能重合）。

课本 p45 两个定理、图 2-11 与“1° 的弧”。左图中 ∠AOB 固定为 60°，拖动 D 改变 ∠COD，表格实时给出圆心角、弧的度数和弦长（半径取 2 计算）；当任一量相等时，另外两个量也相等（吸附到 60°）。

例 1

由相等的圆心角得相等的弦

如图 2-12，$AB$、$AC$、$BC$ 是 $\odot O$ 的弦，$\angle AOC=\angle BOC$．$\angle ABC$ 与 $\angle BAC$ 相等吗？为什么？

解：$\angle ABC$ 与 $\angle BAC$ 相等．在 $\odot O$ 中，

∵$\angle AOC=\angle BOC$，

∴$AC=BC$（）．

∴$\angle ABC=\angle BAC$（）．

练习 1. 在 $\odot O$ 中，$\overset{\frown}{AC}=\overset{\frown}{BD}$，$\angle AOB=50^\circ$．求 $\angle COD$ 的度数．

提示等弧对等圆心角：$\angle AOC=\angle BOD$，两边同时去掉公共部分。
答案$\angle AOC=\angle BOD$ ⇒ $\angle AOC-\angle BOC=\angle BOD-\angle BOC$，即 $\angle AOB=\angle COD$，所以 $\angle COD=50^\circ$．

练习 2. 在 $\odot O$ 中，$\overset{\frown}{AB}=\overset{\frown}{AC}$，$\angle A=40^\circ$．求 $\angle ABC$ 的度数．

提示等弧对等弦：$AB=AC$。
答案$AB=AC$，$\angle ABC=\angle ACB=\dfrac{180^\circ-40^\circ}{2}=70^\circ$．

练习 3. 在 $\triangle ABC$ 中，$\angle C=90^\circ$，$\angle B=28^\circ$，以点 $C$ 为圆心、$CA$ 为半径的圆交 $AB$ 于点 $D$，交 $BC$ 于点 $E$．求 $\overset{\frown}{AD}$、$\overset{\frown}{DE}$ 的度数．

提示连接 $CD$：$CA=CD$，先求圆心角 $\angle ACD$、$\angle DCE$。
答案$\angle A=62^\circ$，$\angle CDA=\angle A=62^\circ$，$\angle ACD=56^\circ$，$\angle DCE=90^\circ-56^\circ=34^\circ$．所以 $\overset{\frown}{AD}$ 为 $56^\circ$，$\overset{\frown}{DE}$ 为 $34^\circ$．

课本 p45–46 例 1 与练习。例 1 的图按 ∠AOC = ∠BOC = 110° 精确绘制（此时 ∠ABC = ∠BAC = 55°）。练习 3 用“圆心角的度数与它所对的弧的度数相等”把求弧转化为求圆心角。

折叠

圆是轴对称图形

在纸上画 $\odot O$，把 $\odot O$ 剪下并折叠，使折痕两旁的部分完全重合，你发现了什么？折痕过圆心 $O$。

圆是轴对称图形，过圆心的任意一条直线都是它的对称轴．（课本 p46）

对称轴是直线：说“直径是圆的对称轴”不准确，应说“直径所在的直线是圆的对称轴”。圆有无数条对称轴。

操作与思考　画 $\odot O$ 的直径 $AB$、弦 $CD$，使 $AB\perp CD$，垂足为 $P$（图 2-13）．在所画图中有哪些相等的线段、相等的弧？

小丽：$PC=PD$．　小明：$\overset{\frown}{AC}=\overset{\frown}{AD}$，$\overset{\frown}{BC}=\overset{\frown}{BD}$．

课本 p46 折纸与操作与思考、图 2-13（右图按 OP = 0.59r 精确绘制，CD ⊥ AB）。让每个学生真的折一次纸。猜想留给下一页用“翻折”验证。

数学实验

沿直径 $AB$ 折叠：$D$ 落在哪里？

翻折角度　

拖动 $C$、$D$ 改变弦 $CD$，再拖“翻折角度”把右半圆沿 $AB$ 折过去．

$\angle APD$ $PC$ / $PD$ $\overset{\frown}{AC}$ / $\overset{\frown}{AD}$ $\overset{\frown}{BC}$ / $\overset{\frown}{BD}$

为什么 $CD\perp AB$ 时，折过去 $D$ 一定落在 $C$ 上？$\overset{\frown}{ADB}$ 与 $\overset{\frown}{ACB}$ 重合（圆的轴对称性）；$\angle APD=\angle APC=90^\circ$，射线 $PD$ 与 $PC$ 重合；两条“线”的交点 $D$ 与 $C$ 重合（图 2-14）。

课本 p47 图 2-14 的翻折。翻折用“右半边横坐标乘 cos(翻折角)”模拟纸片绕 AB 翻转的投影，180° 时恰为关于 AB 的轴对称。先按“设 CD ⊥ AB”，折到 180°：D 与 C 重合，读数两两相等；再把 D 拖开（CD 不垂直于 AB），折过去 D 落在别处——说明“垂直”这个条件必不可少。

证明

垂直于弦的直径

如图 2-15，$AB$ 是 $\odot O$ 的直径，$CD$ 是 $\odot O$ 的弦，$AB\perp CD$，垂足为 $P$．

连接 $OC$、$OD$．在 $\triangle OCD$ 中，

∵$OC=OD$（），$OP\perp CD$，

∴$PC=PD$，$\angle BOC=\angle BOD$（）．

∴$\angle AOC=\angle AOD$（）．

∴$\overset{\frown}{BC}=\overset{\frown}{BD}$，$\overset{\frown}{AC}=\overset{\frown}{AD}$（）．

定理（课本 p47，通常称为垂径定理）

垂直于弦的直径平分弦以及弦所对的两条弧．

半径 $r$、弦心距 $d$、半弦 $\frac a2$ 组成直角三角形：$r^2=d^2+\left(\frac a2\right)^2$。

课本 p47 图 2-15 的推理证明（翻折是“证实”，这里是“证明”）。第 3 行用的是等腰三角形三线合一；第 4 行：∠AOC = 180° − ∠BOC，∠AOD = 180° − ∠BOD。最后的“基本图形”是后面计算题的钥匙。

例 2

同心圆中的两段相等

如图 2-16，在以点 $O$ 为圆心的两个同心圆中，大圆的弦 $AB$ 交小圆于点 $C$、$D$．$AC$ 与 $BD$ 相等吗？为什么？

解：$AC$ 与 $BD$ 相等．过点 $O$ 作 $OP\perp AB$，垂足为 $P$（）．

∵$OP\perp AB$，

∴$AP=BP$，$CP=DP$（）．

∴$AP-CP=BP-DP$，即 $AC=BD$．

同一条 $OP$ 同时垂直于两个圆的弦，垂径定理用两次。

拓展与延伸（图 2-17）　$AB$、$CD$ 是 $\odot O$ 的两条弦，$AB\parallel CD$．$\overset{\frown}{AC}$ 与 $\overset{\frown}{BD}$ 相等吗？为什么？

提示作直径 $MN\perp AB$；因为 $AB\parallel CD$，所以 $MN\perp CD$。
答案相等．由垂径定理，$\overset{\frown}{MA}=\overset{\frown}{MB}$，$\overset{\frown}{MC}=\overset{\frown}{MD}$，相减得 $\overset{\frown}{AC}=\overset{\frown}{BD}$（圆的两条平行弦所夹的弧相等）．

课本 p47 例 2、p48 拓展与延伸。例 2 课本的书写：“∴ AP = BP，CP = DP（垂直于弦的直径平分弦）”。注意 OP 不是直径，但它所在的直线过圆心且垂直于弦，同样适用。图按大圆半径 1、小圆半径 0.6、OP = 0.35 精确绘制。

练习

垂径定理 + 勾股定理

习题 5. 在 $\odot O$ 中，直径 $AB=10$，弦 $CD\perp AB$，垂足为 $E$，$OE=3$．求弦 $CD$ 的长．

提示连接 $OC$：$OC=5$，$OE=3$，在 $\text{Rt}\triangle OCE$ 中求 $CE$。
答案$CE=\sqrt{5^2-3^2}=4$，$CD=2CE=8$（垂直于弦的直径平分弦）．

习题 8. 在直径为 650 mm 的圆柱形油罐内装进一些油后，其横截面如图．若油面宽 $AB=600$ mm，求油的最大深度．

提示过 $O$ 作 $OE\perp AB$，延长交圆于最低点；半径 325，半弦 300。
答案$OE=\sqrt{325^2-300^2}=125$，最大深度 $=325-125=200$ mm．

练习 3（p48）. $\odot O$ 的直径为 10，弦 $AB$ 的长为 8，点 $P$ 在 $AB$ 上运动．求 $OP$ 的取值范围．

提示$OP$ 最短是弦心距（$P$ 为 $AB$ 中点），最长是 $P$ 在端点时。
答案弦心距 $\sqrt{5^2-4^2}=3$，所以 $3\le OP\le5$．

习题 7. $AB$、$AC$ 是 $\odot O$ 的两条弦，且 $AB\perp AC$，$AB=8$，$AC=6$．求 $\odot O$ 的半径．

提示过 $O$ 分别作 $AB$、$AC$ 的垂线，得到矩形：$O$ 到 $AB$ 的距离是 3，到 $AC$ 的距离是 4。
答案半径 $=\sqrt{4^2+3^2}=5$（也可以说明 $BC$ 是直径，$BC=10$）．

课本 p48–49 练习第 3 题、习题 2.2 第 5、7、8 题。油罐图按半径 325、油面宽 600 等比例绘制（油面在圆心下方 125）。四题都回到上一页的“基本图形”：半径、弦心距、半弦组成直角三角形。练习 p48 第 1 题“如何确定圆形纸片的圆心”：对折两次，两条折痕的交点就是圆心——这正好引出下一节。

小结

两种对称性，两组结论

旋转 → 中心对称

同圆或等圆中，圆心角、弧、弦，一组量相等，其余各组量都相等；圆心角的度数 = 所对弧的度数．

翻折 → 轴对称

过圆心的任意一条直线都是对称轴；垂直于弦的直径平分弦以及弦所对的两条弧．

作弦心距、连半径：$r^2=d^2+\left(\frac a2\right)^2$。

思想

用旋转、翻折“证实”猜想，再用推理“证明”。

求弧 → 求圆心角；求弦 → 解直角三角形。
