七年级下册 · 第7章 平面图形的认识（二） · 7.1

探索直线平行的条件

把三角尺的一边紧贴直尺，沿直尺推一推，每推到一个位置就沿三角尺的另一边画一条线。

画出的这些线一定互相平行吗？平行线“永不相交”，可纸再大也画不到无穷远——凭什么判断两条直线平行？

推三角尺画平行线三线八角同位角 · 内错角 · 同旁内角因 · 果 · 理由

课本 p6 图 7-1。封面只抛问题：平行线的定义是“不相交”，但我们无法把直线延长到无穷远去检验，所以要找一个“看得见、量得出”的条件。请学生先猜一猜：推三角尺时，什么东西始终没变？

前情回顾

今天要用到的旧知识

在同一平面内，不相交的两条直线叫做平行线，记作 $a\parallel b$。

基本事实：过直线外一点，有且只有一条直线与这条直线平行。

说清“平行”的意思；7.2 读一读的说理还要用基本事实。

对顶角相等。

两个角的和是 $180^\circ$，这两个角互为补角；邻补角的和是 $180^\circ$。

把“内错角相等”“同旁内角互补”转化成“同位角相等”。

用量角器量角：中心对准顶点，零刻度线对准一边，读另一边所对的刻度。

等式的性质：等量代换（$\angle1=\angle3$，$\angle2=\angle3$，则 $\angle1=\angle2$）。

量一量、比一比角的大小；把两个相等关系“接”起来。

本课主线：两条直线被第三条直线所截，截出的角满足什么条件时，这两条直线就平行？

每出一张卡先请学生口头复述。第一张卡里的“在同一平面内”不能丢（空间里不相交的直线不一定平行）。第二张卡是本课说理的关键工具：后面会两次用“对顶角相等”“邻补角互补”把新条件化归为基本事实。

想一想

$\angle1$ 与 $\angle2$ 不相等，$a$、$b$ 还平行吗？

拖 $b$ 上的橙色点转动直线 $b$；拖 $c$ 上的橙色点改变截线的方向

$\angle1$ $\angle2$

把 $\angle1$ 转得比 $\angle2$ 大一点、小一点，$a$、$b$ 分别在哪一侧相交？$\angle1\gt\angle2$ 时在右侧相交，$\angle1\lt\angle2$ 时在左侧相交；只有 $\angle1=\angle2$ 时不相交。

$\angle1$ 与 $\angle2$ 是否相等，决定了直线 $a$、$b$ 是否平行。

课本 p6 想一想与图 7-3、卡通人的话。交点跑到画面外时，看反馈里的提示（向哪边延长会相交）。让学生注意：只要 $\angle1$ 与 $\angle2$ 差 1°，两条直线迟早会相交——“差一点”也不行。

概念

三线八角：什么样的一对角叫同位角？

如图 7-4，两条直线 $a$、$b$ 被第三条直线 $c$ 所截，一共截出 8 个角。

同位角（课本 p6）

像 $\angle1$ 与 $\angle2$ 这样的一对角称为同位角：在截线 $c$ 的同侧，在被截直线 $a$、$b$ 的同一方（都在上方或都在下方）。

议一议：图中还有其他的同位角吗？在左图上点两个角试一试。
还有 3 对：$\angle3$ 与 $\angle4$，$\angle7$ 与 $\angle8$，$\angle5$ 与 $\angle6$。共 4 对。

同位角说的是两个角的位置关系；它们不一定相等（左图里 $a$、$b$ 不平行，同位角就不相等）。

课本 p6 图 7-4 与议一议。先让学生说出 ∠1、∠2 的位置特点，再归纳“同侧、同方”。点角游戏：点两个角，系统判断是不是同位角，点错了会说出错在哪里（不同侧还是不同方）。同一顶点处的两个角（如 ∠1 与 ∠3）不是同位角。

基本事实 · 例 1

同位角相等，两直线平行

基本事实（课本 p7）

两条直线被第三条直线所截，如果同位角相等，那么这两条直线平行．
简单说成：同位角相等，两直线平行．

例 1　如图 7-5，$\angle1=\angle C$，$\angle2=\angle C$．指出图中互相平行的直线，并说明理由．

解$AB\parallel CD$，$AC\parallel BD$．$\angle1$ 与 $\angle C$ 是 $AB$、$CD$ 被 $AC$ 截成的同位角
因$\angle1$ 与 $\angle C$ 是同位角，且 $\angle1=\angle C$，已知
果所以 $AB\parallel CD$．同位角相等，两直线平行
因$\angle2$ 与 $\angle C$ 是 $BD$、$AC$ 被 $CD$ 截成的同位角，且 $\angle2=\angle C$，已知
果所以 $AC\parallel BD$．同位角相等，两直线平行

要写清：因、果和由因得果的理由。理由常用课本里的基本事实、定义、性质。

课本 p7 基本事实与例 1。“基本事实”是由实践得出、不再证明的结论，后面的说理都从它出发。例 1 关键是第一步“找同位角”：同一个 ∠C，和 ∠1 配对时截线是 AC，和 ∠2 配对时截线是 CD。课本 p7 用“因、果、理由”分析例 1 的书写，用颜色对应。

练一练

找同位角、写理由

1. 如图，$\angle1$ 与 $\angle C$、$\angle2$ 与 $\angle B$、$\angle3$ 与 $\angle C$ 分别是哪两条直线被哪一条直线截成的同位角？

提示 1先看这两个角的顶点：两个顶点所在的那条直线就是截线。
提示 2$\angle1$、$\angle C$ 的顶点 $E$、$C$ 都在 $AC$ 上，截线是 $AC$。
完整解答$\angle1$ 与 $\angle C$：$DE$、$BC$ 被 $AC$ 所截；
$\angle2$ 与 $\angle B$：$DE$、$BC$ 被 $AB$ 所截；
$\angle3$ 与 $\angle C$：$DF$、$AC$ 被 $BC$ 所截．

2. 如图，因为 $\angle A=\angle DEC$，所以 ____ $\parallel$ ____．理由是：________．

提示 1$\angle A$、$\angle DEC$ 的顶点都在 $AC$ 上，截线是 $AC$。
完整解答$AB\parallel DE$．理由是：同位角相等，两直线平行．

3. 如图，$\angle ADE=60^\circ$，$\angle ABE=30^\circ$．
(1) 当 $\angle ABC$ 等于多少度时，$DE\parallel BC$？
(2) 当 $\angle ADF$ 等于多少度时，$DF\parallel BE$？

提示 1(1) $\angle ADE$ 与 $\angle ABC$ 是 $DE$、$BC$ 被 $AB$ 截成的同位角。
提示 2(2) 与 $\angle ADF$ 成同位角的是哪个角？截线还是 $AB$。
完整解答(1) $\angle ABC=60^\circ$ 时，$\angle ABC=\angle ADE$，$DE\parallel BC$；
(2) $\angle ADF=30^\circ$ 时，$\angle ADF=\angle ABE$，$DF\parallel BE$．理由都是：同位角相等，两直线平行．

课本 p7–8 练一练 1–3。找同位角的窍门：两个角的顶点连起来所在的直线就是截线，各角的另一边所在直线就是被截直线。第 3 题是“由结论找条件”，学生容易答成“DE ∥ BC 时……”，提醒：问的是“满足什么条件时平行”。

议一议 · 想一想

只知道其他的角，能判断平行吗？

图 7-6：$\angle2=\angle3$．$a$ 与 $b$ 平行吗？

∵$\angle1$ 与 $\angle3$ 是对顶角，图中位置
∴$\angle1=\angle3$．对顶角相等
又$\angle2=\angle3$，∴ $\angle1=\angle2$．等量代换
∴$a\parallel b$．同位角相等，两直线平行

图 7-7：$\angle2+\angle3=180^\circ$．$a$ 与 $b$ 平行吗？

∵$\angle1+\angle3=180^\circ$，$\angle1$、$\angle3$ 是邻补角
又$\angle2+\angle3=180^\circ$，已知
∴$\angle1=\angle2$．同角的补角相等（$\angle1$、$\angle2$ 都是 $\angle3$ 的补角）
∴$a\parallel b$．同位角相等，两直线平行

课本 p8 议一议（图 7-6）、p9 想一想（图 7-7）与两个卡通人的提示。思路都是“化归”：已知的角不是同位角，就想办法把它换成同位角，再用基本事实。每个“凭什么”先让学生说。

概念

内错角与同旁内角：点两个角，说出关系

内错角、同旁内角（课本 p9）

如图 7-8，像 $\angle2$ 与 $\angle7$ 这样的一对角称为内错角；像 $\angle2$ 与 $\angle5$ 这样的一对角称为同旁内角．
与截线 $c$与被截直线 $a$、$b$形状
同位角同侧同方“F”形
内错角两侧都在 $a$、$b$ 之间“Z”形
同旁内角同侧都在 $a$、$b$ 之间“U”形

议一议：图中还有其他的内错角或同旁内角吗？内错角：$\angle2$ 与 $\angle7$，$\angle4$ 与 $\angle5$；同旁内角：$\angle2$ 与 $\angle5$，$\angle4$ 与 $\angle7$．

课本 p9 图 7-8 与议一议。“内”指在两条被截直线之间，“错”指在截线两侧，“同旁”指在截线同一侧。左图可以随意点两个角：系统会给出同位角 / 内错角 / 同旁内角，同一顶点处的两角给出对顶角或邻补角（七上 6.3）。“F、Z、U”形是帮助识图的口诀，不是定义。

结论 · 例 2

由基本事实说理得到的两个判定

课本 p9

两条直线被第三条直线所截，如果内错角相等，那么这两条直线平行．简单说成：内错角相等，两直线平行．
两条直线被第三条直线所截，如果同旁内角互补，那么这两条直线平行．简单说成：同旁内角互补，两直线平行．

例 2　如图 7-9，$\angle1=\angle2$，$\angle B+\angle BDE=180^\circ$．指出图中互相平行的直线，并说明理由．

解$AB\parallel EF$，$DE\parallel BC$．
∵$\angle1$ 与 $\angle2$ 是 $AB$、$EF$ 被 $DE$ 截成的内错角，且 $\angle1=\angle2$，
∴$AB\parallel EF$．内错角相等，两直线平行
∵$\angle B$ 与 $\angle BDE$ 是 $BC$、$DE$ 被 $AB$ 截成的同旁内角，且 $\angle B+\angle BDE=180^\circ$，
∴$DE\parallel BC$．同旁内角互补，两直线平行

同位角相等 · 内错角相等 · 同旁内角互补——先认清是哪一类角、哪两条被截直线，再选对应的理由。

课本 p9–10 结论框与例 2。强调：后两个判定是由“同位角相等，两直线平行”说理得到的（第 8 页），不是新的基本事实。例 2 两次用到同一条线 DE：一次作截线，一次作被截直线，让学生在图上用手指描出“Z”形和“U”形。

辨一辨

这三种说法，对吗？

如图，$\angle1=\angle2$，所以 $AB\parallel CD$．

✗$\angle1$、$\angle2$ 是 $AD$、$BC$ 被 $AC$ 截成的内错角，应得 $AD\parallel BC$。先看清哪两条直线被截。

两条直线被第三条直线所截，同位角相等．

✗同位角只是位置关系。只有两条直线平行时同位角才相等（第 4、5 页 $a$、$b$ 不平行时就不相等）——这是下一节的内容。

如图 7-8，$\angle2+\angle7=180^\circ$，所以 $a\parallel b$．

✗$\angle2$ 与 $\angle7$ 是内错角，要相等才能判断平行；互补的应该是同旁内角（如 $\angle2+\angle5=180^\circ$）。

① 是哪一类角？　② 是哪两条直线被哪条直线所截？　③ 这类角要“相等”还是“互补”？

每张卡先举手表决“对/错”，再点开。第 1 张最典型：学生看见 ∠1 = ∠2 就写 AB ∥ CD，其实被截的是 AD、BC。第 2 张为 7.2 埋伏笔：“同位角相等 ⇒ 平行”反过来说对不对，下节课研究。

练一练

认角、填理由

1. 如图，$\angle1$ 与 $\angle B$、$\angle3$ 与 $\angle4$、$\angle2$ 与 $\angle4$ 分别是哪两条直线被哪一条直线截成的？它们分别是什么角？

提示 1$\angle3=\angle BAD$，$\angle4=\angle ADB$，它们的顶点都在 $AD$ 上。
完整解答$\angle1$ 与 $\angle B$：$AC$、$BD$ 被 $BE$ 所截，同位角；
$\angle3$ 与 $\angle4$：$AB$、$BD$ 被 $AD$ 所截，同旁内角；
$\angle2$ 与 $\angle4$：$AC$、$BD$ 被 $AD$ 所截，内错角．

2. 如图，(1) 因为 $\angle1=\angle2$，所以 ____ $\parallel$ ____；(2) 因为 $\angle2=$ ____，所以 $AD\parallel BE$；(3) 因为 $\angle1+\angle B=180^\circ$，所以 ____ $\parallel$ ____．并写出理由．

提示 1(1) $\angle1=\angle BAD$，$\angle2=\angle ADC$，截线是 $AD$。
完整解答(1) $AB\parallel CE$，内错角相等，两直线平行；
(2) $\angle E$，同位角相等，两直线平行；
(3) $AD\parallel BE$，同旁内角互补，两直线平行．

3. 如图，直线 $AB$ 与射线 $DE$ 相交于点 $O$，$\angle BOE=130^\circ$，$\angle D=50^\circ$．$AB$ 与 $CD$ 平行吗？为什么？

提示 1与 $\angle D$ 成内错角的是 $\angle BOD$，它和 $\angle BOE$ 是什么关系？
完整解答平行．∵ $\angle BOD=180^\circ-\angle BOE=50^\circ$（邻补角），$\angle D=50^\circ$，∴ $\angle BOD=\angle D$，∴ $AB\parallel CD$（内错角相等，两直线平行）．

课本 p10 练一练 1–3。第 1 题的 ∠3 与 ∠4 学生常说成内错角：提醒看“两条被截直线”是 AB 和 BD，两个角都在截线 AD 的同侧。第 3 题也可以用 ∠AOD = 130°（对顶角）与 ∠D 互补来说明。

2. 如图，$BD$ 平分 $\angle ABC$，$\angle1=25^\circ$，$\angle2=50^\circ$．$ED$ 与 $BC$ 有怎样的位置关系？为什么？

7. 一条临湖道路的两个拐角（$\angle ABC$ 与 $\angle BCD$）都是 $120^\circ$．道路 $AB$ 与 $CD$ 平行吗？为什么？
8. 弯形管道 $ABCD$ 的拐角 $\angle ABC=110^\circ$，$\angle BCD$ 等于多少度时，$CD\parallel BA$？

提示 1第 7 题两个拐角是 $AB$、$CD$ 被 $BC$ 截成的内错角；第 8 题是同旁内角。
完整解答7. 平行，内错角相等，两直线平行．
8. $\angle BCD=70^\circ$ 时，$\angle ABC+\angle BCD=180^\circ$，$CD\parallel BA$（同旁内角互补，两直线平行）．

10. 如图，$\angle1=25^\circ$，$\angle B=65^\circ$，$AB\perp AD$．
(1) $AC$ 与 $BD$ 平行吗？为什么？
(2) 能判断 $AB$ 与 $CD$ 平行吗？如果不能，还应添加什么条件？

提示 1$\angle BAC=\angle BAD+\angle1=90^\circ+25^\circ$；它与 $\angle B$ 是什么角？
完整解答(1) 平行．$\angle BAC+\angle B=115^\circ+65^\circ=180^\circ$，同旁内角互补，两直线平行．
(2) 不能．可添加 $\angle ADC=90^\circ$（即 $CD\perp AD$），则 $\angle BAD+\angle ADC=180^\circ$，$AB\parallel CD$．（答案不唯一）

课本 p11–12 习题 7.1 第 2、7、8、10 题。第 10(2) 是开放题，添加条件的方法不止一种：也可以添加 ∠C = 65°——由 AC ∥ BD 得 ∠C + ∠BDC = 180°（下节课的性质），∠BDC = 115°，∠B + ∠BDC = 180°，所以 AB ∥ CD。鼓励学生说出自己的理由并互相检验。其余习题（第 1、3–6、9 题）留作课后作业。

小结

知识 · 方法 · 思想

知识

三线八角：同位角、内错角、同旁内角。

同位角相等 / 内错角相等 / 同旁内角互补 ⇒ 两直线平行。

方法

找截线（两个顶点所在的直线）→ 定被截直线 → 看位置。

写清因、果和理由；已知的不是同位角，就用对顶角、邻补角把它换成同位角。

思想

“平行（不相交）”看不到无穷远 → 转化成量得出的“角的关系”。

内错角、同旁内角 → 同位角 → 基本事实。
