四年级上册 · 第一单元 · 第 1 课 · 写景散文

观潮

赵宗成　朱明元

边读边想象画面感受自然之美潮来前 · 潮来时 · 潮过后

一　看大潮　→　二　品读　→　三　读与背

“钱塘江大潮，自古以来被称为天下奇观。”先问：你见过大海涨潮吗？今天我们跟着作者去江边“看”一次大潮——边读边在脑子里放电影。

一 · 看大潮潮来前
潮来前

钱塘江大潮，自古以来被称为天下奇观。

农历八月十八是一年中传统的观潮日。这一天早上，我们来到了海宁市的盐官镇，据说这里是观潮最好的地方。

我们随着观潮的人群，登上了海塘大堤。宽阔的钱塘江横卧在眼前。

江面很平静，越往东越宽，在雨后的阳光下，笼罩着一层蒙蒙的薄雾。

镇海古塔、中山亭和观潮台屹立在江边。远处，几座小山在云雾中若隐若现。

江潮还没有来，海塘大堤上早已人山人海。大家昂首东望，等着，盼着。

潮还没来，江面“很平静”。可人呢？“人山人海”“昂首东望，等着，盼着”——大家都急着看。读“等着，盼着”要慢一点，读出期待。

一 · 看大潮潮来时 · 先听见
潮来时

午后一点左右，从远处传来隆隆的响声，好像闷雷滚动。

顿时人声鼎沸，有人告诉我们，潮来了！

我们踮着脚往东望去，江面还是风平浪静，看不出有什么变化。

过了一会儿，响声越来越大，只见东边水天相接的地方出现了一条白线，人群又沸腾起来。

潮还没看见，先听见“闷雷滚动”。让学生闭上眼睛听老师读这一段，想一想：先听到什么，又看到什么？

一 · 看大潮潮来时 · 扑面而来
潮来时

那条白线很快地向我们移来，逐渐拉长，变粗，横贯江面。

再近些，只见白浪翻滚，形成一堵两丈多高的水墙。

浪潮越来越近，犹如千万匹白色战马齐头并进，浩浩荡荡地飞奔而来；

那声音如同山崩地裂，好像大地都被震得颤动起来。

镜头一步步拉近：白线 → 水墙 → 千万匹白色战马。最后一句画面在“抖”——大地都被震得颤动起来！这是全文最精彩的一段，后面还要背。

一 · 看大潮潮过后
潮过后

霎时，潮头奔腾西去，可是余波还在漫天卷地般涌来，江面上依旧风号浪吼。

过了好久，钱塘江才恢复了平静。看看堤下，江水已经涨了两丈来高了。

“霎时”——潮头一下子就过去了，可余波还在“漫天卷地”，“风号浪吼”。“江水已经涨了两丈来高”，大约有两层楼那么高。

二 · 品读 · 课后第 2 题

排一排：作者按什么顺序写大潮？

三幅画面被打乱了。按大潮出现的先后，点一点排好顺序。

按时间顺序写：潮来前 → 潮来时 → 潮过后。哪一部分写得最多、最细？——潮来时。

课后第 2 题前半。排好后追问：三部分里，人群有什么变化？（人山人海、昂首东望 → 人声鼎沸、踮着脚 → 人群又沸腾起来）人群越来越激动，也衬出了大潮的壮观。

二 · 品读 · 课后第 2 题

潮来时：听声音，看样子

午后一点左右，从远处传来隆隆的响声，好像闷雷滚动。……过了一会儿，响声越来越大，只见东边水天相接的地方出现了一条白线，人群又沸腾起来。

那条白线很快地向我们移来，逐渐拉长，变粗，横贯江面。再近些，只见白浪翻滚，形成一堵两丈多高的水墙。浪潮越来越近，犹如千万匹白色战马齐头并进，浩浩荡荡地飞奔而来；那声音如同山崩地裂，好像大地都被震得颤动起来。

声音：闷雷滚动 → 越来越大 → 山崩地裂
样子：一条白线 → 拉长变粗 → 水墙 → 白色战马

课后第 2 题后半：脑海中浮现出怎样的画面？一步一步点，让学生先“听”再“看”。作者抓住了大潮声音和样子的变化，由远到近写。请学生合上书，看着右边的图，说说大潮来时的样子。

二 · 品读 · 课后第 3 题

连一连：古诗里的大潮

浪淘沙（其七）

[唐] 刘禹锡

八月涛声吼地来，头高数丈触山回。

须臾却入海门去，卷起沙堆似雪堆。

须臾：一会儿。海门：江河入海的地方。

先点左边一句诗，再点右边课文里意思相近的句子。

一千多年前，诗人看到的也是这样的大潮——“吼地来”“头高数丈”，和课文写的一样雄壮。

课后第 3 题。配对答案不止一种（如“卷起沙堆似雪堆”也可以对“白浪翻滚”），说出理由就行。读诗时让学生想象课文里的画面。

二 · 品读 · 资料袋

为什么这里的潮特别大？

喇叭口：杭州湾外宽内窄，东面湾口宽达一百千米，到盐官镇附近只有两千余米。

沙坎：江底泥沙堆成庞大的沙坎，从东往西逐渐升高。

所以：潮水从宽宽的湾口涌进来，越往西江面越窄、江底越高，潮就越来越高——形成了壮观的大潮。

课后资料袋。用手比一比：两只手掌张开像喇叭，往里一收——水被挤得越来越高。示意图不按比例，只帮助理解。

三 · 读与背 · 课后第 1 题

背诵第 3～4 自然段

按“先听到 → 再看到 → 越来越近”的顺序背。想不起来，点一下空格偷看一个字。

课后第 1 题。先看图说顺序：闷雷滚动 → 一条白线 → 拉长变粗 → 水墙 → 战马 → 山崩地裂，再逐级挖空背诵。

回顾

天下奇观

观　潮
潮来前　江面平静　人山人海　等着，盼着
潮来时　声音：闷雷滚动 → 越来越大 → 山崩地裂
　　　　样子：白线 → 拉长变粗 → 水墙 → 白色战马
潮过后　余波涌来　风号浪吼　涨了两丈来高

边读边想象：抓住声音和样子的变化，就能在脑子里“看见”“听见”大潮。

回扣单元要素：边读边想象画面，感受自然之美。课后可以找找钱塘江大潮的视频看一看。
