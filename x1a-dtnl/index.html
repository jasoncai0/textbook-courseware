一年级上册 · 第二单元 · 汉语拼音 4

看图说话认识声母 d t n l拼读音节儿歌《轻轻跳》认识“马 土 不”

课本 26–27 页。先看画面：舞台上谁在表演？小姑娘手里拿着什么？小男孩在做什么？

一 · 看图说话

舞台上，谁在表演？

点图上闪烁的圆圈：小男孩敲鼓，鼓和鼓棒像 d，“打”的声母是 d；小姑娘的伞把像 t；半圆的拱门像一个门洞 n；高高举起的鼓棒像一根小棍 l。先请孩子说，再点开验证。

二 · 认一认

声母 d t n l

按一下出现一个字母并“写”出来，点卡片重放。记字形：左下半圆 d d d，伞把朝下 t t t，一个门洞 n n n，一根小棍 l l l。b 和 d 容易混：b 的半圆在右边，d 的半圆在左边。读 t 时有气冲出来，读 n 时气从鼻子出来。

三 · 拼读

拼一拼，读一读

课本 26 页下方的音节表全部在这里。点一个音节，先读声母、再读韵母，按“拼一拼”。最后两个 nǚ lǘ 要特别注意：n l 和 ü 相拼，ü 上的两点不能省（女 nǚ，驴 lǘ）。

四 · 读儿歌

轻轻跳

轻轻跳

小兔小兔轻轻跳，

小狗小狗慢慢跑。

要是踩疼小青草，

我就不跟你们好。

（郑春华）

课本 27 页。先听老师读，再借助拼音自己读。“要是”的“是”、“你们”的“们”读轻声。说一说：小兔、小狗为什么要轻轻跳、慢慢跑？——它们怕踩疼小青草，爱护小草。【拍手读】先读通儿歌，再按“拍手读”：一拍亮一个字，全班跟着拍手、一字一拍地读，读出儿歌的节奏；再点一下停。这样设计是让孩子在节拍里把每个音节读清楚、读完整。

五 · 认一认

马 土 不

课本 27 页右上角的词语“马路、泥土”，儿歌里的“不”。点左边的字，读字、读词。“不”在第四声前读 bú（不要 bú yào）。

六 · 写一写

d t n l 在四线三格里

课本 27 页下方。d 先写左半圆，再写竖（从上格写到中格下线）；t 先写竖右弯（竖的上头在上格中间），再写横（在第二条线上）；n 先写竖，再写门洞；l 一笔竖，从上格写到中格下线。

回顾

今天学会了

左下半圆 d，伞把朝下 t
一个门洞 n，一根小棍 l
n l 见了 ü，两点不能省

记一记：b 和 d 是反着的——b 的肚子在右边，d 的肚子在左边。

齐读板书，背一背儿歌《轻轻跳》。
