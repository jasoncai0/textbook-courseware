回忆我的母亲

回忆性散文：事件典型、细节真实平实语言里的深情叙事中穿插议论

翻品质卡　→　走母子时间轴　→　找议论句　→　品平实的句子

从一块“家织布”说起：母亲亲手纺出线，请人织成布，染了颜色。问：做这样一块布的人，是怎样的人？预习提示：中共中央挽联“八路功勋大孝为国，一生劳动吾党之光”——这位母亲为什么能获得如此高的评价？课件中母亲与作者都只画背影、手部和物件。

思考探究一

母亲的“勤劳”和品格，藏在哪些事里？

按 → 逐张出示品质卡，或直接点左边的卡片，看看课文里的事例。

开头说“特别是她勤劳一生”，“勤劳”是全文的核心。先请学生找事例，再归纳品格。“母亲最大的特点是一生不曾脱离过劳动”——从年轻到老年，从生“我”前一分钟到八十多岁“尤喜纺棉”。

理清脉络

母亲的一生，“我”的道路

两条线交织：母亲始终在土地上劳动；“我”一步步走出家乡，走上革命道路。母亲给“我”的，正是走这条路的力量。

按 → 逐个时间点出示。上行写母亲，下行写“我”。注意时间词：从“我能记忆时起”到“去年”“现在”。文章以时间为序，叙事中又不断穿插议论。

母亲是个好劳动平实如话，字字是情

母亲是个好劳动。从我能记忆时起，总是天不亮就起床。

全家二十多口人，妇女们轮班煮饭，轮到就煮一年。母亲把饭煮了，还要种田，种菜，喂猪，养蚕，纺棉花。因为她身体高大结实，还能挑水挑粪。

母亲这样地整日劳碌着。

记得那时我从私塾回家，常见母亲在灶上汗流满面地烧饭，我就悄悄把书一放，挑水或放牛去了。

一连串动词“种田，种菜，喂猪，养蚕，纺棉花”，没有一个形容词，却写尽辛劳。“我就悄悄把书一放”——孩子不声不响地分担，母子之情尽在不言中。

思考探究三

叙事中穿插的议论

下面哪些是议论性的语句？找出来。

“灾难不因为中国农民的和平就不降临到他们身上”：由一家之苦，看到千千万万农民的苦难，引出“我”反抗压迫的思想。

“只有这种知识，这种意志，才是世界上最可宝贵的财产”：把母亲给的教益提升为人生信念。

“正是这千百万人创造了和创造着中国的历史”：由一位平凡的母亲，到千百万劳动人民——这是全文的升华。

议论句的作用：点明事例的意义，深化主题，把对母亲的爱与对人民、民族的情感连在一起。注意它们都紧跟在叙事之后，不空发议论。

积累拓展四

平实的句子，深藏的情感

先读一读，说说你读出了什么，再点开看看。

母亲这样地整日劳碌着。

“这样地”总括前面的种种劳动，“整日”写时间之长。一句平静的总结，饱含儿子的心疼。

这类地主富人家看也不看的饭食，母亲却能做得使一家人吃起来有滋味。

“看也不看”与“有滋味”对比，一个“却”字写出母亲的聪明能干，也写出贫苦中母亲给家人的温暖。

母亲年老了，但她永远想念着我，如同我永远想念着她一样。

两个“永远”，母子之情双向流动；不能回家看望的愧疚，也藏在这平平的一句里。

母亲生我前一分钟还在灶上煮饭。

“一分钟”是极言其短，以最具体的时间写母亲“一生不曾脱离过劳动”，令人震撼。

积累拓展四。本单元要“品味风格多样的语言”：鲁迅简洁幽默，朱德平实如话。可让学生把句子改得华丽一些再比较——反而不如原句动人。

思考探究二

“我应该感谢母亲”：母亲给了“我”什么？

与困难做斗争的经验在三十多年的军事生活和革命生活中再没感到过困难
强健的身体，勤劳的习惯使我从来没感到过劳累
生产的知识和革命的意志鼓励我以后走上革命的道路

“我用什么方法来报答母亲的深恩呢？”

我将继续尽忠于我们的民族和人民，尽忠于我们的民族和人民的希望——中国共产党，使和母亲同样生活着的人能够过快乐的生活。这是我能做到的，一定能做到的。

由小爱到大爱：报答母亲，就是让千百万像母亲一样的人过上快乐的生活。

思考探究二。“忠孝不能两全”的遗憾（“竟未能报答母亲的希望”），在结尾化为更大的报答。朗读结尾“这是我能做到的，一定能做到的”，读出坚定。

读写迁移 · 平实中见深情

用一件小事写亲人

学课文：不用华丽的词，用动词和具体的数字、细节说话；写完事，加一句朴素的议论或感受。

积累拓展五提示：可比较阅读邹韬奋《我的母亲》、老舍《我的母亲》，看看不同作者笔下的母亲形象、写法与语言风格。

回顾

一位平凡的母亲，千百万劳动者的一员

写了什么怎么写
勤劳一生、聪明能干、俭朴宽厚、同情穷苦、深明大义典型事例，按时间顺序
母亲给“我”的教益叙事中穿插议论
对母亲的爱、对人民的爱平实如话，饱含深情

史沫特莱笔下的母亲

她比一般妇女要高大一些，强壮一些，裤子和短褂上，左一块右一块都是补丁，两只手上突显着粗粗的血管……两只大大的褐色眼睛里充满了贤惠，充满了忧愁。

——摘自史沫特莱《伟大的道路》（课后补白）

补白中的外貌描写是别人写的，课文却几乎没有外貌描写——为什么？（儿子写母亲，写的是记忆里她做的事；母亲的形象在劳动中立起来）
