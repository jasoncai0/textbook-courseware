多边形的内角和与外角和

小学里，我们把三角形的 3 个角剪下来拼在一起，发现“三角形的内角和是 $180^\circ$”。

拼一拼只能说明“这几个”三角形，能不能说明理由？四边形、五边形……$n$ 边形的内角和又是多少？绕一块草地走一圈，一共转了多少度？

转动直线平行线说理分成三角形外角拼成周角

课本 p28 开篇。封面三个问题对应本课三段：三角形内角和的说理、多边形内角和公式、多边形外角和。最后一个问题来自 p34 练一练 1（小明绕六边形草地走一周）。

前情回顾

今天要用到的旧知识

把三角形的 3 个角拼在一起，正好拼成一个平角：内角和是 $180^\circ$。

本课用平行线把“拼”变成“说理”。

两直线平行，同位角相等、内错角相等、同旁内角互补。

过顶点作平行线，把三个内角“搬”到一起。

平角 $=180^\circ$，周角 $=360^\circ$；邻补角的和是 $180^\circ$。

角平分线把角分成相等的两个角。

求外角、外角和；例 2、例 3 中的角平分线。

本课主线：三角形内角和 $180^\circ$ 的理由 → $n$ 边形内角和 → 多边形外角和。

第一张卡请学生回忆小学的“撕角拼角”。追问：“量、拼都有误差，而且只试了几个三角形，能说明所有三角形都是 180° 吗？”——引出说理的必要。

试一试

说明“三角形的内角和是 $180^\circ$”

思路：过点 $A$ 作 $AC'\parallel BC$，把 $\angle C$ “搬”到点 $A$ 处，三个角就拼在了一起。

作过点 $A$ 作 $AC'\parallel BC$．过直线外一点有且只有一条直线与这条直线平行
∴$\angle CAC'=\angle C$，两直线平行，内错角相等
$\angle BAC'+\angle B=180^\circ$．两直线平行，同旁内角互补
又$\angle BAC'=\angle BAC+\angle CAC'=\angle BAC+\angle C$，角的和
∴$\angle BAC+\angle C+\angle B=180^\circ$．等量代换

结论

三角形的内角和是 $180^\circ$．

课本 p28 试一试与两个卡通人的说理。“作 AC′ ∥ BC”是添加的辅助线，图中用虚线表示。可以请学生换一种作法：过 A 作 BC 的平行线后，用两对内错角（∠B、∠C 都搬到 A 处，和 ∠BAC 拼成平角）——这正是小学“拼角”的数学化。

例 3

四边形中的角平分线

例 3　如图 7-35，在四边形 $ABCD$ 中，$\angle A$ 与 $\angle C$ 互补，$\angle ABC$、$\angle ADC$ 的平分线分别交 $CD$、$AB$ 于点 $E$、$F$．$\angle1$ 与 $\angle2$ 有怎样的数量关系？为什么？

解$\angle1$ 与 $\angle2$ 互余．
∵$\angle A+\angle ABC+\angle C+\angle ADC=(4-2)\times180^\circ=360^\circ$，四边形内角和
又$\angle A+\angle C=180^\circ$，∴ $\angle ABC+\angle ADC=180^\circ$．
∵$BE$、$DF$ 分别平分 $\angle ABC$、$\angle ADC$，∴ $\angle1=\dfrac12\angle ABC$，$\angle2=\dfrac12\angle ADC$．
∴$\angle1+\angle2=\dfrac12(\angle ABC+\angle ADC)=90^\circ$，即 $\angle1$ 与 $\angle2$ 互余．

和例 2 一样：求的是两个角的和，用内角和公式先求出“另两个角的和”。

课本 p31 例 3。图按 ∠A + ∠C = 180°（四个顶点在同一个圆上）用坐标画出，BE、DF 是精确的角平分线，量得 ∠1 + ∠2 = 90°。第 2 步先请学生量一量、猜一猜。

概念

多边形的外角

图 7-36 中，把 $\triangle ABC$ 的边 $AB$ 延长，得到 $\angle CBD$；图 7-37 中，把五边形 $ABCDE$ 的边 $AB$ 延长，得到 $\angle CBF$．

外角（课本 p32）

多边形的一边与它的邻边的延长线组成的角，叫做多边形的外角．
在多边形的每个顶点处分别取多边形的一个外角，这些外角的和叫做多边形的外角和．

一个外角和它相邻的内角有什么关系？互补（是邻补角）：外角 $=180^\circ-$ 相邻的内角．

外角的一边是多边形的边，另一边是邻边的延长线；$\angle CBD$ 的两边是 $BC$ 和 $AB$ 的延长线 $BD$。

课本 p32 图 7-36、7-37 与外角、外角和的定义。注意“每个顶点处取一个外角”：每个顶点处其实有两个外角（对顶角，相等），外角和只取其中一个。

做一做

把外角剪下来，顶点重合在一起

把外角移到点 $O$

三角形$\angle\alpha+\angle1=180^\circ$，$\angle\beta+\angle2=180^\circ$，$\angle\gamma+\angle3=180^\circ$
又$\angle1+\angle2+\angle3=180^\circ$，∴ $\angle\alpha+\angle\beta+\angle\gamma=$ $180^\circ\times3-180^\circ=360^\circ$
四边形$\angle\alpha+\angle\beta+\angle\gamma+\angle\delta=$ $180^\circ\times4-180^\circ\times2=360^\circ$

五边形、六边形的外角和是多少度？都是 $360^\circ$。

想一想 · 议一议

$n$ 边形的外角和；剪掉一个角之后

每个顶点内角 + 相邻的外角 $=180^\circ$，$n$ 个顶点共 $n\cdot180^\circ$
∴外角和 $=n\cdot180^\circ-(n-2)\cdot180^\circ=$ $360^\circ$

内角和随边数增加，外角和永远是 $360^\circ$——求边数时常常先用外角。

小结

知识 · 方法 · 思想

知识

三角形内角和 $180^\circ$；$n$ 边形内角和 $(n-2)\cdot180^\circ$。

多边形的外角和等于 $360^\circ$，与边数无关。

方法

把分散的角“搬”到一起（三角形内角和）。

求两个角的和，不必求出每个角（例 2、例 3）。

思想

多边形 → 三角形；外角 → 内角的补角。

三角形、四边形、五边形……→ $n$ 边形。

本章回顾：7.1–7.2 平行线 → 7.3 平移 → 7.4 三角形 → 7.5 内角和与外角和：平行线是本章说理的“发动机”。

请学生用自己的话说出三个结论的来历（平行线 / 分三角形 / 内角与外角互补）。课后作业建议：习题 7.5 第 1–5、7、8、11 题。
