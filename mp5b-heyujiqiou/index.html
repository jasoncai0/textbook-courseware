和与积的奇偶性

随手翻开数学书，左、右两边页码的和，是奇数还是偶数？

不用算，你能先猜出来吗？今天我们像数学家一样：举例、观察、发现规律、再验证。

多写算式配对的点子找规律举例验证

课本 p50–51 综合与实践。先让学生翻书试两次，记下结果，再提出问题：为什么总是这样？这节课以探究为主，重在经历“举例—观察—猜想—验证—说理”的过程。

前情回顾

奇数和偶数，你能说说它们的特点吗？

是 2 的倍数的数叫作偶数；不是 2 的倍数的数叫作奇数。

判断和、积是奇数还是偶数。

个位是 0、2、4、6、8 → 偶数；

个位是 1、3、5、7、9 → 奇数。

很快看出算出来的和、积是奇是偶。

偶数个东西能正好两两配对；奇数个总会多出 1 个。

用“配对的点子”说清为什么。

今天的问题：和、积是奇数还是偶数，与加数、乘数有什么关系？

课本 p50 开头小精灵的问题“你能说说奇数和偶数各有什么特点吗”。第 3 张卡是本课说理的关键：偶数 = 若干对；奇数 = 若干对 + 1 个。

观察填好的表格，说说你的发现。（提示：看两个加数分别是奇数还是偶数）

想一想为什么

用配对的点子，看看和为什么是奇数或偶数

第一个数5
第二个数7

两个奇数相加，为什么和是偶数？　每个奇数都多出 1 个，两个“多出来的”正好凑成一对，就没有多出来的了。

点子竖着两个一对排列，奇数多出的那 1 个用橙色画在最右边。点“合在一起”，第二个数的点子接到第一个数后面，两个落单的点（如果有）会凑成一对。先演示 5 + 7，再请学生换成“偶 + 偶”“奇 + 偶”说一说。

发现规律

两个数的和，奇偶有什么规律？

偶数 + 偶数 = 偶数

对 + 对 = 对

奇数 + 奇数 = 偶数

落单的两个凑成一对

奇数 + 偶数 = 奇数

还剩 1 个落单

和是奇数还是偶数，与两个加数是奇数还是偶数有关。

你能再举一些例子，验证自己的发现吗？　$123+456=$ （奇 + 偶 = 奇）　$77+99=$ （奇 + 奇 = 偶）

课本 p50 三个小精灵的发现。先让学生说，再点开。最后两个算式请学生自己算，验证规律：先按规律猜奇偶，再算出结果核对。

翻一翻

打开数学书，左、右两边页码的和是奇数还是偶数？

左、右两边的页码有什么关系？　是相邻的两个自然数：左边是偶数，右边是比它大 1 的奇数。

任意两个相邻自然数的和呢？　相邻的两个自然数，一个奇数、一个偶数，和一定是奇数。

你知道这是为什么吗？　奇数 + 偶数 = 奇数。也可以想：$n+(n+1)=n\times2+1$，是 2 的倍数多 1。

课本 p50 下方的问题。书的第 1 页在右边，所以翻开后左页是偶数、右页是奇数。“随手翻开”在 2～120 页之间随机翻。

连加

几个数连加，和是奇数还是偶数？

点数字卡片放进连加算式（最多 8 个），先猜和的奇偶，再看结果。

和的奇偶与加数中奇数的个数有什么关系？　奇数有 1 个、3 个、5 个……（单数个），和是奇数；奇数有 2 个、4 个、6 个……（双数个），和是偶数。偶数的个数不影响。

$1+3+5+\cdots+29$ 的和是奇数还是偶数？为什么？

加数一共有 个，都是奇数，所以和是 。

提示 1从 1 到 29 的奇数：1、3、5、……、29，数一数有几个？（$(29+1)\div2$）
完整解答有 15 个奇数，15 是单数，所以和是奇数（算一算：和是 225）。

课本 p51 小组讨论。卡片上有奇数和偶数，学生选好后系统数出奇数的个数，并算出和。重点引导：只看奇数的个数——每两个奇数凑成一个偶数。

积

几个数的乘积，什么情况下是奇数？什么情况下是偶数？

每排5
排数3

$1\times3\times5=15$$1\times2\times3=6$
$8\times4\times10=640$$3\times5\times7\times2=210$

左边两个算式和右边两个算式，各有什么共同点？

乘数都是奇数，积是 奇数；乘数都是偶数，积是 偶数。

几个乘数中，只要有一个是偶数，积一定是 偶数。

课本 p51 积的奇偶性。左边点阵：每排几个 × 排数。只要有一个乘数是偶数，就能把点子两排两排（或两列两列）配对，全部配完——积是偶数；两个乘数都是奇数时，右下角总剩 1 个——积是奇数。表格是课本的四个算式。

用规律

不计算，直接判断奇偶

$99+100+101$

加数中有 2 个奇数（99、101），双数个，和是偶数（300）。

$1\times3\times5\times7\times9\times11$

乘数都是奇数，积是奇数。

$23\times46$

有一个乘数 46 是偶数，积一定是偶数。

$11+13+15$

3 个奇数相加（单数个），和是奇数（39）。

学生先举手判断，再点开说理由。每题都可以让学生算出结果验证。

回顾

说说探索和发现规律的体会

和偶 + 偶 = 偶；奇 + 奇 = 偶；奇 + 偶 = 奇。连加时，奇数有单数个 → 和是奇数，双数个 → 和是偶数。
积乘数都是奇数 → 积是奇数；只要有一个乘数是偶数 → 积是偶数。

多写一些算式，并进行比较，才能发现规律。

要注意从不同的算式中发现共同的特点。

举例和验证是发现规律的好方法；用点子配对，还能说清“为什么”。
