孤独之旅

孤独，也能是一场“旅行”吗？

一个十来岁的少年，一条小船，一群鸭子，一片望不到边的芦荡。

梳理人物的心理变化体会环境描写的烘托作用结合生活体验理解“成长”

自读课，围绕“阅读提示”和旁批展开：这是一篇描写少年成长之路的小说，紧扣杜小康的心理变化，大量环境描写起烘托作用。课文节选自《草房子》第八章，杜家家道中落，杜小康失学，跟父亲去放鸭。

离家 · 前行是纯粹的旁批：杜雍和为什么这样做？

杜家的独生子杜小康失学了，只好跟着父亲去放鸭。

杜小康“我不去放鸭了，我要上岸回家……”

杜雍和沉着脸，绝不回头去看一眼。

鸭群在船前形成一个倒置的扇面形，奋力向前推进，同时，造成了一个扇面形水流。

前行是纯粹的。

旁批一：杜雍和“绝不回头”，是怕自己也“突然地对前方感到茫然和恐惧，从而也会打消离开油麻地的主意”——父亲也害怕，只是不能说。“前行是纯粹的”单独成段：没有退路，只能向前。鸭群的扇面形水流写得很细，也是一种“前行”。

芦荡 · 孤独与磨难旁批：这里的环境描写有什么作用？

当杜小康一眼望去，看到芦苇如绿色的浪潮直涌到天边时，他害怕了——这是他出门以来第一回真正感到害怕。

日子一天一天地过去了，父子俩也一天一天地感觉到，他们最大的敌人，也正在一步一步地向他们逼近：它就是孤独。

天黑，河水也黑，芦苇荡成了一片黑海。杜小康甚至觉得风也是黑的。

杜小康忘记了父亲，朝一股鸭子追去。

他感到脚钻心地疼痛，他顾不得去察看一下。

旁批：“极致的孤独，对人物来说意味着什么？”“与之前的茫然、恐惧相比，暴风雨中杜小康的表现是怎样的？”三个“黑”字层层渲染，暴风雨既是自然的磨难，也是心灵的考验。注意他“忘记了父亲”，独自去追——他开始承担了。

雨后 · 长大旁批：这里杜小康为什么哭了？

那十几只受了惊的鸭，居然一步不离地挨着主人蹲了下来。

他哭了起来，但并不是悲哀。他说不明白自己为什么想哭。

雨后天晴，天空比任何一个夜晚都要明亮。杜小康长这么大，还从未见过蓝成这样的天空，而月亮又是那么的明亮。

他觉得自己突然地长大了，坚强了。

“蛋！爸！鸭蛋！鸭下蛋了！”

旁批：“这里杜小康为什么哭了？”——不是悲哀，是委屈、疲惫、释放，也是被鸭子依偎时的感动，说不清，所以真实。“暖色的结尾，充满希望”：鸭蛋是辛苦的收获，也是成长的果实。

阅读提示 · 本课独有

杜小康的心理阶梯：一级一级走上来

成长之路：茫然 → 恐惧 → 孤独想家 → 适应 → 坚强 → 长大。孤独压迫着他，也锤炼着他——这就是“孤独之旅”。

阅读提示：小说紧扣杜小康的心理变化展开。按 → 小人一级一级往上走，右边出示原文依据和当时的环境；也可以点任意台阶。注意第 3 级到第 4 级：“他们已根本不可能回避孤独了。这样反而好了”——接受了孤独，才开始适应。

景里有心：每一处环境烘托了怎样的心情？

先点左边一句环境描写，再点右边的心情词。配对成功会显示它的作用。已配对 0 / 5

作用：环境描写烘托人物心情、推动情节、营造诗一般的氛围——芦荡的“大”与“黑”压迫着杜小康，雨后的“蓝”与“亮”映照着他的成长。

阅读提示第二段：大量的环境描写对人物起到了很好的烘托作用，富有韵味的语言营造了诗一般的氛围。请学生先自己配对，说出理由；再读一读“萤火虫”一段，体会小说的诗意。

回顾

孤独之旅

旅程：离开油麻地 → 到达芦荡 → 暴风雨 → 雨后 · 鸭下蛋

心理：茫然 → 恐惧 → 孤独想家 → 适应 → 坚强 → 长大

环境：陌生的水面 · 绿色的浪潮 · 黑海 · 蓝得透亮的天空——烘托心情

题目：放鸭的孤独旅程，也是少年的成长之旅

本单元三篇小说都与“少年”有关：《故乡》里少年的“我”与闰土，《我的叔叔于勒》里少年若瑟夫的眼光，《孤独之旅》里少年杜小康的成长。可以组织一次比较：少年的眼睛看到了什么？
