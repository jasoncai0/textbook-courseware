八年级上册 · 第六单元 · 第 23 课 · 文言文

得道者多助，
失道者寡助。

《孟子》三章

借助注释，整体感知积累文言词语和名言警句熟读成诵

孟子“以雄辩著称”——他是怎样把道理一步步说服人的？

预习：孟子名轲，战国时期思想家，儒家学派代表人物之一，被尊称为“亚圣”。《孟子》是记录孟子及其弟子言行的著作。本课三章分别出自《公孙丑下》《滕文公下》《告子下》，题目是编者加的。孟子处在诸侯争霸、战争频繁的时代，他主张行仁政。

读 · 得道多助，失道寡助

先开“节奏”齐读，再开“注释”“译文”。读准：“亲戚畔之”的“畔”同“叛”。画面是“三里之城，七里之郭”被围而不能攻下——想一想，为什么“环而攻之而不胜”？

读 · 富贵不能淫

这是一段对话：景春问，孟子答。分角色读，景春的语气是佩服、反问；孟子的语气先是反问驳斥，后面三个排比句要读得斩钉截铁。“丈夫之冠也”的“冠”读 guàn。

读 · 生于忧患，死于安乐

“傅说”的“说”读 yuè；“空乏其身”的“空”读 kòng；“曾益”的“曾”读 zēng；“法家拂士”的“拂”读 bì。六个人名连读，要读出排比的节奏。

思考探究一、二

孟子的论证链：一环扣一环

先选一章，让学生说“下一环是什么”，再点“展开下一环”核对。三章的论证方式各不相同：第一章由小到大、层层推进；第二章先破后立；第三章先举例再归纳，由个人推到国家。思考探究一还要求另举事例证明观点，可以在展开到最后一环时请学生补充。

思考探究三

“以雄辩著称”：读出排比的气势

城非不高也，池非不深也，兵革非不坚利也，米粟非不多也，委而去之……

四个“非不……也”，把守城的条件一一摆足，再一转“委而去之”——条件越好，越见得“人和”重要。

居天下之广居，立天下之正位，行天下之大道。……富贵不能淫，贫贱不能移，威武不能屈。

两组三句排比，句式整齐、斩钉截铁，把“大丈夫”的标准说得掷地有声。

舜发于畎亩之中，傅说举于版筑之间，……苦其心志，劳其筋骨，饿其体肤，空乏其身……

六个人物一气列举，五个“使他……”层层加码，事例充分，气势逼人，结论水到渠成。

反复朗读，越读越快、越读越重，让学生体会排比“增强气势、加强说服力”的效果。可以请学生比较：把四个“非不……也”删成一句“城池坚固，粮食充足”，气势差在哪里？

思考探究二

谁才配称“大丈夫”？

景春眼中：公孙衍、张仪

“一怒而诸侯惧，安居而天下熄”——权势大，能左右天下。

孟子：他们只会揣摩诸侯的心意、曲意顺从，“以顺为正者，妾妇之道也”。

≠

孟子心中：真正的大丈夫

立身：居广居（仁）· 立正位（礼）· 行大道（义）

处世：得志，与民由之；不得志，独行其道

气节：富贵不能淫，贫贱不能移，威武不能屈

标准不同：景春看的是权势，孟子看的是人格与操守。

注释提醒：“以顺为正者，妾妇之道”反映了旧时婚姻中男女地位不平等，是错误的封建伦理；孟子借此类比纵横家不讲仁义礼、只知曲意顺从。课后背诵“居天下之广居……此之谓大丈夫”。

积累拓展四

字词梳理：打开抽屉，点卡片看释义

积累拓展四要求翻译五个句子，句中的关键词都在这里：畔、熄、淫、移、屈、衡、作、喻、法家拂士、敌国。翻译时注意通假字和使动用法。

思考探究一、二

背诵：两章 + 一段

沿着论证链背：论点 → 两个论据 → 三个“不以” → 中心论点 → 结论。背不出时先想“下一环是什么”，再点空格偷看一个字。

积累拓展五

选一句作为座右铭，说出理由

选一句孟子的话：

座右铭要“落到自己身上”：先解释，再联系一件自己的事，最后说打算。也可以从课外《孟子》篇目选，如“穷则独善其身，达则兼善天下”。

回顾

《孟子》三章

得道多助，失道寡助富贵不能淫生于忧患，死于安乐
天时 < 地利 < 人和 → 得道者多助
层层推进 · 正反对比		驳“权势即丈夫” → 立仁、礼、义
先破后立 · 类比 · 排比		六人事例 → 个人 → 国家
举例归纳 · 由人及国

孟子的雄辩：论证有层次，句式多排比，气势逼人；核心都是“仁政”与“人格”。

本单元主题“人应该有怎样的品格与志趣”：孟子的回答是——行仁义，守气节，在忧患中成长。
