百分数与分数、小数的互化

5 分钟仰卧起坐：王红完成了指定个数的 1.15 倍，李芳完成了指定个数的 110%。

一个是小数，一个是百分数——谁完成的个数多？

小数 ⇄ 百分数分数 ⇄ 百分数小数点搬家三联转换器

课本 p86 例 2 情境。先让学生猜，再问：两个数样子不一样，怎样才能比？——要先变成同一种数。

前情回顾

这节课要用到的老朋友

$\dfrac{64}{100}=64\%$

分母是 100 的分数，把分子后面加上“%”就是百分数。

小数、分数都先变成“分母是 100”。

一位小数表示十分之几，两位小数表示百分之几，三位小数表示千分之几：

$0.3=\dfrac{3}{10}$　$0.248=\dfrac{248}{1000}$

试一试：把小数改写成分母是 100 的分数。

分数化成小数，用分子 ÷ 分母：

$\dfrac35=3\div5=0.6$

例 3：分数先化成小数，再化成百分数。

还记得吗？一个数乘 100，小数点要向右移动两位（五上 小数点移动引起的变化）。今天它会派上大用场。

第 1 张卡接上一课。第 4 条提示是“小数点搬家”规律的根据，可以请学生口算 0.248×100。

例 2

1.15 和 110%，哪个大？

要知道谁完成的个数多，只要比较 1.15 和 110% 哪个大。怎样比？

办法一：把小数改写成百分数

$1.15=\dfrac{\ ?\ }{100}$ 　$=$

$115\%\ \bigcirc\ 110\%$　

办法二：把百分数改写成小数

$110\%=\dfrac{110}{100}=$

$1.15\ \bigcirc\ 1.1$　

答：谁完成的个数多？

$1.15>110\%$，王红完成的个数多。

两种办法都是先把两个数变成同一种数再比较。百分数也可以大于 100%：110% 就是指定个数的 1.1 倍。

课本 p86 例 2。比较符号的空可以填 >（英文键盘 Shift+.）。追问：“110%”比 100% 多，说明什么？——李芳超额完成了。

试一试

小数和百分数之间，小数点怎样“搬家”？

$0.3=\dfrac{3}{10}=\dfrac{\ ?\ }{100}$ $=$ %

$0.248=\dfrac{248}{1000}=\dfrac{\ ?\ }{100}$ $=$ %

把百分号前面的数和原来的小数比一比，你有什么发现？小数点向右移动了两位：0.3 → 30%，0.248 → 24.8%。

小数 → 百分数：小数点向右移动两位，添上“%”（位数不够用 0 补足）。
百分数 → 小数：去掉“%”，小数点向左移动两位。

课本 p86 试一试第 1、2 题。下方演示：先选一个数，再点“搬家”。小数点每次移一位，位数不够时补的 0 用橙色显示（如 0.3 要补成 0.30）。百分数 → 小数时同理向左移（27% → 0.27，150% → 1.5，13.5% → 0.135）。

你会用百分数表示这些分数吗？

会游泳的会溜冰的

先把分数改写成小数，再改写成百分数。

(1) $\dfrac35=3\div5=$ $=$ %

(2) $\dfrac27=2\div7\approx$ $=$ %

$2\div7=0.285714\cdots$ 除不尽。课本规定：计算中遇到除不尽时，一般保留三位小数（即在百分号前面保留一位小数）。$0.2857\cdots\approx0.286=28.6\%$。

有的分数也可以直接化成分母是 100 的分数：$\dfrac35=\dfrac{60}{100}=60\%$。$\dfrac27$ 能这样化吗？不能：100 不是 7 的倍数，只能先做除法。

课本 p87 例 3。第 (2) 题的两个空按字面判：必须是 0.286 和 28.6（保留三位小数）。可以让学生用竖式算到第四位 0.2857，再四舍五入。

三联转换器

分数、小数、百分数，改一个，另外两个跟着变

分数用“/”输入，如 3/8；改哪个格子都可以。

试一试 $\dfrac13$：小数和百分数为什么带“≈”？$1\div3=0.333\cdots$ 除不尽，只能取近似值 $0.333=33.3\%$；百格图上涂的是准确的 $33\dfrac13$ 格。

本课核心工具。可以让学生出题考同桌：一人在任一格输入，另一人先口答另外两种写法，再看转换器。转换器用分数精确计算：能除尽的写“=”，除不尽的按课本保留三位小数并写“≈”。右边的百格图按准确值涂色（超过 100% 时用第二个百格图）。

小结

三种数，可以互相转化

“百分之几”就是“分母是 100”。小数点向右移两位 ⇔ 乘 100。

比较不同形式的数，先转化成同一种形式——和例 1 把分数都化成分母 100 是一个道理。
