七年级上册 · 第6章 平面图形的认识（一） · 6.3

余角、补角、对顶角

把一副三角尺靠在直尺上，三角尺转来转去，两侧的角 $\angle\alpha$、$\angle\beta$ 一个变大、一个变小——它们的和变不变？

两千多年前，墨子让光穿过一个小孔，墙上出现了倒立的人像。两条光线在小孔处交叉，形成的角有什么关系？

余角与补角同角的余角相等对顶角相等说理：因为…所以…

课本 p159、p161 情境。本课是第 6 章第一次系统“说理”：从度数关系出发，推出“同角的余角相等”“对顶角相等”两条结论，每一步都要讲依据。封面两个问题对应本课两部分。

前情回顾

今天要用到的旧知识

直角 $=90^\circ$，平角 $=180^\circ$；角可以相加、相减：$\angle AOC=\angle AOB+\angle BOC$。

“两个角的和是直角 / 平角”就是余角、补角的定义。

回看 6.2 角 →

$\angle AOC$、$\angle BOD$ 都是直角，不管 $\angle COD$ 多大，总有 $\angle AOD=\angle BOC$。

今天要说清楚它的道理：同角的余角相等（第 7 页）。

设未知数，根据相等关系列方程：$x+(x+30)=180$，解得 $x=75$。

已知两角的关系求度数（例 1）。

概念

余角与补角

余角（课本 p159）

如果两个角的和是一个直角，那么这两个角互为余角，简称互余，其中的一个角叫做另一个角的余角（complementary angle）．

图 6-26：$\angle\alpha=35^\circ$，$\angle\beta=55^\circ$，$\angle\alpha$ 与 $\angle\beta$ 互为余角

补角（课本 p159）

如果两个角的和是一个平角，那么这两个角互为补角，简称互补，其中的一个角叫做另一个角的补角（supplementary angle）．

图 6-27：$\angle\alpha=45^\circ$，$\angle\beta=135^\circ$，$\angle\alpha$ 与 $\angle\beta$ 互为补角

互余、互补说的是两个角之间的数量关系，两个角不一定挨在一起（上面两个图里它们就是分开的）。

钝角有余角吗？没有：钝角已经大于 $90^\circ$。只有锐角才有余角；锐角、直角、钝角都有补角。

课本 p159 定义与图 6-26、6-27。两幅小图按课本度数精确绘制，两个角分开画——强调定义只看“和”。“互为”的意思：∠α 是 ∠β 的余角，∠β 也是 ∠α 的余角。

议一议 · 说理

同一个角的两个余角，相等吗？

$\angle1=$

如果 $\angle1$ 与 $\angle2$ 互为余角，$\angle1$ 与 $\angle3$ 互为余角，那么 $\angle2$ 与 $\angle3$ 相等吗？为什么？

因为$\angle1$ 与 $\angle2$、$\angle1$ 与 $\angle3$ 互为余角已知
所以$\angle1+\angle2=90^\circ$，$\angle1+\angle3=90^\circ$余角的定义
即$\angle2=90^\circ-\angle1$，$\angle3=90^\circ-\angle1$等式的性质
由此可知$\angle2=\angle3$都等于同一个式子 $90^\circ-\angle1$

如果 $\angle\alpha$ 与 $\angle\beta$ 互为补角，$\angle\alpha$ 与 $\angle\gamma$ 互为补角，那么用同样的方法可以说明 $\angle\beta=180^\circ-\angle\alpha=\angle\gamma$。

由此，我们得到（课本 p160）

同角（等角）的余角相等．
同角（等角）的补角相等．

课本 p160 议一议。左图就是 6.2 习题 8 的图：∠AOC、∠BOD 都是直角，∠1 = ∠COD 是“同一个角”，∠2 = ∠BOC、∠3 = ∠AOD 是它的两个余角。拖滑块看读数始终相等——这是“看出来”；右边一行一行写出来才是“说出来”。“等角”：如果 ∠1 = ∠4，那么 ∠1 的余角与 ∠4 的余角也相等（因为都等于 90° 减去同一个度数）。

例题 · 练一练

用方程求角；用结论说理

例 1（课本 p160） 已知 $\angle\alpha$ 与 $\angle\beta$ 互为补角，且 $\angle\beta$ 比 $\angle\alpha$ 大 $30^\circ$．求 $\angle\alpha$、$\angle\beta$ 的度数．

两个未知角，两句话：“互补”给出和，“大 $30^\circ$”给出差——用一个角表示另一个，列方程。

解：$\angle\beta=\angle\alpha+30^\circ$根据题意
∵$\angle\alpha$ 与 $\angle\beta$ 互为补角已知
∴$\angle\alpha+\angle\beta=180^\circ$补角的定义
即$\angle\alpha+(\angle\alpha+30^\circ)=180^\circ$代入，列方程
∴$\angle\alpha=75^\circ$，$\angle\beta=75^\circ+30^\circ=105^\circ$解方程

练一练 1（p161） 如果 $\angle1=\angle2$，$\angle2=\angle3$，那么 $\angle1$ $\angle3$；如果 $\angle1\gt\angle2$，$\angle2\gt\angle3$，那么 $\angle1$ $\angle3$．

练一练 2（p161） 如图，$\angle A+\angle B=90^\circ$，$\angle BCD+\angle B=90^\circ$．$\angle A$ 与 $\angle BCD$ 有怎样的大小关系？为什么？

提示$\angle A$ 和 $\angle BCD$ 都是谁的余角？
完整解答$\angle A=\angle BCD$。因为 $\angle A$ 与 $\angle BCD$ 都是 $\angle B$ 的余角，所以 $\angle A=\angle BCD$（同角的余角相等）。

课本 p160 例 1、p161 练一练 1、2。例 1 也可以设 ∠α = x° 列方程，与第 4 章联系。练一练 2 的图按 ∠ACB = 90°、CD ⊥ AB 精确绘制（三角形边长 3、4）；书写时括号里写“同角的余角相等”。

读一读 · 概念

小孔成像里的角：对顶角

墨子让一个人对着小孔站在屋外，屋内墙上出现了倒立人像：光沿直线传播，头部的光到了下边，足部的光到了上边。

通过小孔 $O$ 的两条光线 $AA'$、$BB'$ 形成了 4 个角：$\angle AOB$、$\angle AOB'$、$\angle A'OB'$、$\angle A'OB$．

对顶角（课本 p161）

$OA'$ 是 $OA$ 的反向延长线，$OB'$ 是 $OB$ 的反向延长线，我们把 $\angle AOB$ 和 $\angle A'OB'$ 叫做对顶角（opposite angles）．$\angle AOB'$ 和 $\angle A'OB$ 也是对顶角．

① 有公共顶点；② 一个角的两边分别是另一个角两边的反向延长线——两条直线相交才有对顶角。

你能举出生活中的对顶角的实例吗？剪刀的两个刀刃与两个把手、交叉的两根木条、马路上斜交的两条斑马线……

课本 p161 读一读与对顶角的定义。左图是代码绘制的光路示意：A、O、A′ 在一条直线上，B、O、B′ 在一条直线上，所以 ∠AOB 与 ∠A′OB′ 是对顶角（标同色）。注意对顶角是“位置关系”，与余角、补角（数量关系）不同。

想一想 · 说理

转动木条：对顶角有什么关系？

$\angle1$$\angle2$ $\angle3$$\angle4$

如图 6-29，将两根木条 $a$、$b$ 钉在一起，看成两条相交直线．如果 $\angle1=50^\circ$，那么 $\angle2$、$\angle3$、$\angle4$ 各等于多少度？$\angle2=130^\circ$，$\angle3=50^\circ$，$\angle4=130^\circ$。

拖动木条 $b$ 改变 $\angle1$ 的大小，发现的结论仍成立吗？

因为$\angle1$、$\angle3$ 都是 $\angle2$ 的补角$\angle1+\angle2=180^\circ$，$\angle3+\angle2=180^\circ$（平角）
所以$\angle1=\angle3$同角的补角相等
同样$\angle2=\angle4$都是 $\angle1$ 的补角，同角的补角相等

由此，我们得到（课本 p162）

对顶角相等．

课本 p162 想一想（图 6-29）与试一试（图 6-30）。拖木条 b 的橙色端点，四个读数实时变化（由坐标计算），学生会看到 ∠1 = ∠3、∠2 = ∠4 始终成立，相邻两角和始终是 180°。再按 → 写出说理过程：这里用到了刚学的“同角的补角相等”——新结论建立在旧结论上。

议一议 · 辨一辨

三条直线交于一点，有几对对顶角？

如图 6-28，直线 $AB$、$CD$、$EF$ 相交于点 $O$．先自己数，再点“下一对”验证．

一共有6 对：每两条直线组成 2 对，三条直线有 $AB$ 与 $CD$、$AB$ 与 $EF$、$CD$ 与 $EF$ 三种组合，$3\times2=6$。

辨一辨：下面的说法对吗？

有公共顶点且相等的两个角是对顶角．

✗如一个角的平分线分成的两个角，有公共顶点、相等，但边不是反向延长线。对顶角相等，相等的角不一定是对顶角。

两条直线相交，$\angle1$ 与 $\angle2$ 相邻，则 $\angle1+\angle2=180^\circ$．

✓它们合起来是一个平角（第 10 页的读数也可以验证）。

课本 p162 议一议（图 6-28）。“下一对”依次高亮 6 对对顶角，两个角分别用橙、蓝弧标出，读数（由坐标计算）相等。前 3 对是相邻射线组成的角，后 3 对是“跨过一条射线”的较大的角，学生最容易漏数后 3 对。辨析第 1 题是对顶角定义的逆命题，为八年级“命题”埋伏笔。

例题

对顶角 + 余角：一步一步求

例 2（课本 p162） 如图 6-31，直线 $AB$、$CD$ 相交于点 $O$，$\angle BOD$ 与 $\angle BOE$ 互为余角，$\angle AOC=72^\circ$．求 $\angle BOE$ 的度数．

已知 $\angle AOC$，要求 $\angle BOE$：中间缺一座“桥”——$\angle BOD$：它与 $\angle AOC$ 是对顶角，又与 $\angle BOE$ 互余。
解：∵$\angle AOC$ 与 $\angle BOD$ 是对顶角看图：$OB$、$OD$ 是 $OA$、$OC$ 的反向延长线
∴$\angle BOD=\angle AOC=72^\circ$对顶角相等
又∵$\angle BOD$ 与 $\angle BOE$ 互为余角已知
∴$\angle BOD+\angle BOE=90^\circ$余角的定义
∴$\angle BOE=90^\circ-\angle BOD=90^\circ-72^\circ=18^\circ$等式的性质

课本 p162–163 例 2。图按题中数据精确绘制：∠AOC = ∠BOD = 72°，∠BOE = 18°，∠DOE = 90°。思路分析强调“找桥梁”：已知角 → 对顶角 → 余角。书写每步都要括号注明依据。

小结

知识 · 方法 · 思想

知识

互余：和为 $90^\circ$；互补：和为 $180^\circ$（只看度数，不看位置）。

同角（等角）的余角相等，同角（等角）的补角相等；对顶角相等。

方法

因为……所以……，括号写依据：定义、已学的结论。

找“桥梁”角：对顶角、余角、补角、平分线；数量关系复杂时列方程。

思想

先研究度数和（余、补），再用它说明图形中的位置关系（对顶角）。
